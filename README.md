# 拾字 PWA Beta

这是一个本地运行、可安装到手机主屏幕的汉字书写恢复工具。当前目标是 Pre-App 阶段的高保真功能合流版：先把真实记忆逻辑和高保真核心体验打磨成可连续自测的 PWA Beta，再决定是否进入原生 App / TestFlight / App Store。

## 主要文件

- `index.html`：产品主页面（界面与逻辑，约 120KB）。
- `deck-data.js`：内置题库数据（SEED 词卡 + GROUPS 部件分组，约 1.9MB，由生成脚本产出，勿手改）。
- `hanzi-writer.min.js`：汉字笔顺渲染库。
- `fsrs6.min.js`：固定版本、完全离线的 FSRS-6 跨天调度器。
- `THIRD_PARTY_NOTICES.md`：第三方库版本与许可证。
- `data/`：Hanzi Writer 的单字笔画数据，以及离线字源数据 `etymology.json`。
- `scripts/`：生成数据和验证页面的脚本。
- `generated/`：当前生成出的 8105 字覆盖率报告和 6854 个可写候选字结构化结果。
- `sources/`：生成脚本依赖的原始字表、字频和词典数据。
- `ios/ShiziApp/`：iOS 原生 WKWebView 外壳工程，用于真机安装和 TestFlight 内测。
- `CHANGELOG.md`：按版本记录产品逻辑和 UX 调整。
- `requirements.txt`：生成脚本需要的 Python 依赖。

当前界面采用「生宣白 × 墨色 × 朱砂印」的产品语言。首页只保留日期时辰、每日题记、主印章和今日拾得，「收字」收进今日区域；核心数据仍来自真实字库、记忆模型、复习调度和本地存储，界面改版不改变题库和记忆模型的底层逻辑。每日题记从《书谱》《笔论》《礼记·学记》《进学解》《论语·学而》《诗经·卫风·淇奥》和《试笔》中选取 52 条原文，并常驻标明作者与篇名；同日刷新稳定，换日轮换与「今日一字」独立。

界面永久遵守两条约束：一屏至多一个实心朱红，并且它就是本屏主行动；印章只用于品牌和完成后留下的刻痕。标题级大字使用汉字数字，正文、统计和日期继续使用阿拉伯数字。

排印使用 11 / 12 / 13 / 15px 四档小字号、8 / 12 / 16 / 24px 间距节奏，以及 .12em 标签 / .26em 题记两档字距；固定品牌字内嵌一个 4.2KiB 的开源 LXGW WenKai WOFF2 子集，Android 另有 DFKai / AR PL UKai / TW-Kai fallback，离线与跨平台不会退成随机衬线体。浅色和深色都带低对比宣纸纤维，章印落下有短促墨晕，反馈吉祥物会按结果呈现平静、欣慰或关切；系统开启“减少动态效果”时关闭眨眼和墨晕。印历、月帖和年度报告沿用同一套宣纸与朱砂语言，不设置目标、排名或断签惩罚。

练习卡的题面是「词语挖空＋拼音」：其他字给出语境，缺的字只显示拼音，避免同音字歧义，也不会把答案泄在题面上。首批人名与冷门语境已逐条人工批准，只保留无需解释的常用词；其余改用不含目标字的「拼音 + 白话释义」，不再拿冷门词证明冷门词。语境覆盖只改题面，不改目标字、读音和用户记忆键。点「写好了」后进入「你写的 / 范字」对照；提交快照冻结当时仍可见的点拨笔画和用户墨迹，结果显示与自动比对读取同一份完整快照。不会写时点「不会写」，先照轮廓描红一遍，再隐藏答案立即独立写一次；描红只算教学，不算掌握。

结果页提供「写对了 / 写错了」两个默认同权的明确动作，以及小号的「不太确定」出口；只有自动比对给出明确建议时，对应动作才变为视觉主按钮。不太确定会盖「补拾」、进入本组再练，不会直接毕业。当逐笔几何检查明确认为差异较大、且本回合没用点拨时，选择写对会出现一次轻量确认，整体覆盖度检查不拦截，最终仍由用户决定；选择写错会自动叠上范字笔画，立即看清差异。系统根据本回合事实显示为独立写对 / 稍后再练 / 写错 / 没写出，并保留拾到 / 补拾 / 待补 / 再拾的盖章动画和历史标签。普通反馈最多停留约 1.8 秒，点击结果区可立即换题，连续点击不会跨过下一题；「重盖」会在这 1.8 秒内保持可用，原子回滚记忆、组内队列、每日统计和对应 FSRS 事件，再回到同一份提交快照。跨卡重盖浮条会暂时替代顶栏而不与返回和收字入口重叠。

普通组达到 20 次尝试或约 6 分钟后，只在换题间隙提醒一次。可以继续完成本组，也可以把尚未写稳和还没写到的字按原顺序排到明天最前面；选择继续后，本组不再重复提醒。首次校准仍完整走完摸底和结果说明，不被节奏提醒截断。

字格左上角的「点拨」是普通回忆阶段的唯一辅助入口：轻点播放下一组笔画，按住暂时瞥一眼完整真实字形，松手即隐藏且不改变提示次数。点拨播放时会淡化用户笔迹，播完自动恢复；「撤一笔」和「重写」只在落笔后出现在字格右上角。看提示写对、自由书写写错和点击「不会写」都会在本组稍后再写；只有一次全新的、不看提示也不描红的独立写对才能毕业。练习页不提供收字入口，避免中途分心；从字库详情进入的单字练习退出即散，不占首页续练，并回到原来的字库。关键控件点击区不低于 44pt，375×667 矮屏完整容纳「不会写 → 描红 → 自己写」操作。

点「写好了」的瞬间会做本地自动比对（毫秒级、离线）：笔画数相同走逐笔配对，笔画数不同或点拨笔画与用户笔迹重叠时走整体覆盖判断，连笔、断笔和重复覆盖不会机械地被当成多余笔画。自动比对只高亮建议，不预提交、不锁定选择，最终正确性始终以用户判断为准；比对不会在书写过程中泄题。

书写画布使用一套共享 Canvas2D 笔锋渲染器：慢写更饱满、快写更轻，Apple Pencil 有压感时优先采用压感；起笔略顿、收笔出锋，快笔带极轻飞白，起笔与明显停顿有不超过 2px 的洇墨。渲染层只附加宽度与速度，不改变自动比对读取的 `x/y` 坐标；减少动态效果或低端设备会保留首尾锥形并关闭飞白、洇墨。最近手写、日帖和月帖复用同一笔锋数据，旧备份里只有坐标的墨迹仍按正常笔宽显示。

有 v2 矢量手写的单字详情会出现「做张字卡」；独立写出后每天最多给一次不打断换题的轻提示，也可在「我的 → 设置 → 字卡提示」关闭。字卡只重绘最近保存的这份笔迹，配小字拼音、干支日期、小「拾」章和更小的「拾字」落款；没有墨迹就不显示入口，不用印刷目标字补位。旧备份中只有带字格 PNG 的 v1 墨迹仍可查看，但不会生成字卡，详情会提示重新独立写一次。可切换 1080×1440 的 3:4 社交竖版与 1080×1080 的 1:1 头像方版，均为 2x PNG；iOS 可直接存到相册或系统分享，浏览器使用 Web Share / 下载降级。图片不含口号、二维码、下载引导、设备信息或完整练习记录。

落笔进入「灶台模式」：题面、顶栏和底部动作约 200ms 退场，字格角落工具保留三成可见，停笔 2 秒后恢复；第一次使用会等首笔写完才退场，描红阶段相同。每次从页面入口进入练习，首卡只出现一次轻纸面揭开；结算大章下从固定文案库显示一句收笔语。「我的 → 设置 → 练字背景音」可选关 / 雨声 / 炉火，默认关闭，与盖章和描红的纸墨声音完全独立；背景音只在习字页程序化循环，进入结果、离开练习、锁屏或切后台即淡出。系统开启“减少动态效果”时改为直接显隐。

当前练习节奏：系统计划通常每组 15 个不同目标字，到期复习或题库末尾可能形成短组；每天最多安排 30 个到期字，按逾期与近期困难程度优先，练完后即可回到新字。同一困难字在组内重复任意次数仍只占一个目标名额。顶部只显示「已练 X / Y 个」和按字去重的「另有 N 个字要再练」；单字练习不显示进度，所有目标字出现但仍有困难字时不会提前结算。session v2 会保存普通组的墨迹、提示层、提交快照、描红阶段和再练队列；返回、刷新、跨午夜或 iOS 杀后台后都可原位继续，单字练习退出则直接散去。当天完整做完第一组后，「今日已拾」完成态不再回退；「我的」印历用紧凑的「盖章 N天」统计所选月份的落印日期，用「累计 N天」显示累计练习日，读屏会完整说明为「累计练习 N 天」。累计值沿用升级前的历史打开日，升级后只在完整练完一组的日期增加；印历不设月目标。累计第 1 / 7 / 14 / 30 个练习日、第 100 天后每满 100 天，以及练过第 100 / 300 个不同字时会显示一次里程碑；历史继承跳过的档位不会补弹庆祝，字数里程碑当天的备份提醒会让位。

跨天调度使用固定的 `ts-fsrs 5.2.0 / FSRS-6.0`：期望保留率 0.90、最长间隔 365 天、开启 interval fuzz，只使用 Again 与 Good。看提示写出、写错和不会写记录 Again；最终不看提示独立写对记录 Good。组内重现完全由再练队列控制，不采用 FSRS 的分钟/小时 due；困难字毕业后才启用按本地自然日记录的 `dueDay`，且最早是次日。

「写得不稳的字」根据本地练习记录直接列出练习中没写出的字，每字只陈述 `没写出 N 次`，再用一句白话指出更值得留意的一类字。样本不足时只提示继续观察；达到门槛后，某一主题或结构至少包含 3 个写得不稳的字，才作为第二视角出现。点具体字会打开单字详情，唯一主行动会把这一组字直接带入练习。

首页尚未盖章且没有未完成组时展示按日期确定的「今日一字」，带语境词和拼音，点击即可单字练习；同日刷新不变，次日更换。首次盖章后它自动退场，首页只展示当天的「今日拾得」（最多 50 字），不再回退昨日数据。字库用连续六列字墙展示所有练过的字，墨色由深到淡表达记忆状态；单字点击后从底部打开详情，可查看最近手写、对范字、回放笔顺或再写一遍。详情故事区另有一行不超过 20 字的字源与出处；当前离线数据覆盖字频前 1000 字中的 906 字及 212 个部首字中的 207 个，来源、匹配规则与人工抽校记录见 `sources/etymology.README.md`。繁简一对多必须结合固定卡片语境人工选定字头，不可读古注也必须人工转写，否则整行安静缺席。

新用户第一次点击「先练 15 个字」会进入一组轻校准题，练习页会提示“先写一组，之后会按你的情况调整难度”。前两张固定为熟悉但容易提笔卡住的「尴 / 嚏」，尽早让用户感受到产品用途；中段完成难度校准，最后四张封顶在 85，避免最难题紧贴结算。首卡的「点拨 / 不会写」从渲染完成起即可使用，3 秒只切换帮助文案、不锁按钮；校准期第一次卡住会就地说明一时想不起来很正常。已有练习记录的用户不会被重新打断。

每组 15 字内部会做会话内自适应：连续独立写对会把后续新字推向更高难度，用过提示、不太确定和写错会小幅回退，连续点「不会写」才明显降级。首次校准只有在用户自评写对与几何检查一致时才完整计入挑战档门槛；几何不一致或不可用的写对按半次计，避免早期难度被误推过高。每组结束后还可以标记“太简单、刚刚好、太难、词不自然”，这些整组反馈会持久化为个人难度偏移和语境严格度，下次打开仍然生效。

产品不承诺固定“六分钟”：首启给出「约 6–8 分钟」的范围并说明写不出时会提供提示，首页仍说明“一组字，按自己的节奏”，因为描红与组内再练会按实际失手次数自然增长。校准结算页在 iOS 上就地邀请开启练习提醒，默认仍关闭；开启后通知直接给出一个到期或最近没写出的字的语境词与拼音，点开进入该字练习，没有可练目标就不推。浏览器则直接显示明日日期，给出明确的回访预期。

字库页和设置里可以切换六个在学字库：常用三千五、进阶三千、生僻字、小学、初中、高中。当前 6854 字基础数据按规范等级实际为一级 3500、二级 2868、三级 486，因此第三库诚实显示「生僻字」与实际总数，不承诺尚未进入题库的约 1600 个三级字。字库卡片只显示库名、「已练 X / 共 Y」和换库入口，不增加进度分层或完库时间预测。字库只决定接下来出现哪些新字；已练字、今天要复习的字、搜索、收字与自定义字始终跨库保留。新用户校准前默认常用三千五，校准为挑战后自动切到进阶三千；用户手动换过库后不再被校准覆盖。旧版的常用/实用偏好迁入常用三千五，挑战偏好迁入进阶三千；每张题卡原有的太简单、太生僻、词不自然、不想练仍作为内部质量与排序反馈，不会覆盖记忆反馈。

底部导航是 3 个单层楷体 tab：**习字 / 字库 / 我的**。
- **习字**：首页只有日期时辰、每日题记、大印章「拾」和今日一字 / 今日拾得。新用户先进入 15 字校准；老用户优先完成每天最多 30 个今天要复习的字，预算耗尽后可继续练新字。
- **字库**：连续六列字墙展示所有练过的字，墨色越淡表示越值得再写；顶部每天只给一条行动、回想或发现，搜索框同时承接查字与收字。
- **我的**：同页放置当月印历、最多三个写得不稳的字、本月拾字帖、设置与备份、年度报告五个层级。字库、提醒、纸墨声音、练字背景音、字体和数据管理都进入二级设置页；清空当前数据以危险色单独隔开。

「我的 → 设置 → 更大字体」提供标准/大字两档。字号偏好保存在当前设备并进入备份，所有主要文字通过同一个缩放变量同步变化；承载状态、图例和动作后果的文字至少使用 13px 与较高对比色。320×568 矮屏下练习动作仍在首屏，揭晓页保留写得不稳的字入口，较低优先级的题目反馈可在揭晓区域内滚动到达。

「收字」用来抓现实里提笔忘的字：应用内输入面板边输边预览识别出的字（在库字直接带出拼音，练过的会标出来），Enter 或「收进字库」确认；也可以点「拍一个字」，现场拍照或从相册选择。iOS 只在当前设备用 Vision 给出候选，识别结果不会自动收字，必须亲自点选；浏览器和识别失败场景直接手输。入口只在首页今日区域和字库即时搜索，练习中不提供入口。

手动输入的字若在基础字库中，会直接激活对应卡片（带拼音、语境词和部件提示），并按一次真实的「不会写」记入记忆模型，之前的「太简单/太生僻」等排除标记也会被清掉；练习外加入会按添加顺序排在下一组非校准练习最前，写过一次后恢复正常调度。普通手动输入的不在库字仍可生成自定义卡片；拍字遇到暂不支持练习的字则先保存记录，并列入字库「暂不支持练习」，不会生成无笔顺练习。拍字照片中心裁切并压到单张不超过 64KiB，浏览器支持时使用 WebP，iOS WKWebView 无法编码 WebP 时自动回退 JPEG；全局最多 30 张并按约 420KiB 总预算淘汰最旧照片。详情可回看，照片默认保存在当前设备；主动导出备份时会包含在备份文件中，应用不会在后台上传。重置卡组时自定义字、拍字来源和暂不支持练习的字一并清空。

「我的 → 设置」里的数据区收着导出备份、恢复备份和清空当前数据；“我的”主层另有独立备份行常驻显示上次成功备份时间。完成 5 个练习日或记录 30 字后，连续 7 天未备份会温和提醒，第 3 个完成日的结算页也会提示一次。练过第 100 / 300 个字当天先完成里程碑庆祝，备份提醒延后显示。备份按白名单导出用户数据，并包含 session v2、FSRS 状态与日志、描红教学标记、本地漏斗、补帖记录、拍字来源/照片、字卡提示偏好和月帖/字卡可用的最近墨迹，不包含测试、瞬态键或设备内安全副本。漏斗只在当前设备幂等记录首启、校准、次日回访、对照分歧、备份和完整组时长，不含设备标识，也不会主动联网发送。恢复前会对比当前/备份字数和最后日期；恢复或清空前自动保留最近一份设备内安全副本，完成后页面底部会短暂显示一次撤销入口。安全副本不会随入口消失，下次恢复或清空会覆盖它；它不会进入导出文件，也不能抵御卸载或整站数据被清除。换手机或清浏览器数据前仍需导出备份。

每组结束后会进入结果页；首次校准同样保留难度说明和完整「今日拾得」字帖。字块依次落下，最后再盖大章并同步触觉。图例只说明首次结果：无标记代表独立写对，金菱代表看过提示或不确定，朱砂代表写错或没写出；回炉后独立毕业会显示可读的「已独立」并给章加金边。仅在有字第一次没写稳时提示“点任意字块，可单独再练”，并提供可选的「再写一遍」口袋和「看看写得不稳的字」入口。「存为字帖」为标准 15 字组生成 1080×1440 本地 PNG；若习字中途收字超过 15 个，画布会逐行延长并保留整组内容。每格重绘本组最终一次有效提交的真实用户笔迹，没落笔就留白，不拿印刷目标字冒充手写；iOS 调起系统分享面板，浏览器优先使用 Web Share，不支持时下载图片。图片只读取本组笔迹、结果、日期和本次里程碑，不读取用户、设备或完整练习记录。待复习单字仍由字库统一管理。

「我的」首屏直接嵌入当月印历：实际练过是实心「拾」印，后来补帖是浅色「补」印，其余日期保持留白；可左右翻月。最近 7 天的空白日可以发起一组 5 字补帖，只有完整写完并结算才落印，中途退出保留当前组但不会补印。补帖日期和当前真实练习日分别记账，重复恢复或重复结算不会多落一枚章。

「本月拾字帖」随时聚合当月练过、真正稳定的已拾回、独立写出、盖章天数和最难独立字，生成 1080×1440 本地 PNG，并复用日帖的原生分享 / Web Share / 下载通道。每个字只保留最近一次独立书写的 120px WebP 缩略图；全局最多 96 份、按 UTF-16 保守估算不超过约 420KiB，空间紧张时先淘汰最旧墨迹，月帖自动用楷体补位，绝不牺牲调度记录。「年度拾字报告」是四屏本地滚动页，汇总本年练过的不同汉字数、盖章天数最多的月份、练过的字里最少见的一个，以及这一年练的第一个字；报告不会上传，也不与他人比较。

PWA 已配置 manifest、iOS 主屏幕图标、standalone 显示模式和 service worker。安装时会预缓存首日校准组与高频核心共 600 字（约 1.23 MiB），应用外壳、FSRS-6 和这些笔顺可直接离线运行；其余字首次需要联网下载一次，随后按需缓存。离线未缓存时页面会明确说明原因，仍允许点「写好了」并自行判断，「不会写」教学使用系统字形 fallback，不会卡死在单张卡片；恢复网络后未落笔的当前卡会自动重试。

## 线上版本（发给朋友测就用这个）

- 地址：<https://eim-aa.github.io/shizi-app/>
- 发布方式：GitHub Pages 从 `main` 分支根目录自动构建——`git push` 到 main 就是发布，一两分钟后生效。页面走「网络优先」缓存策略，用户下次打开会自动拿到新版。
- 手机安装：iPhone 上用 Safari 打开 → 分享按钮 → 「添加到主屏幕」，之后从主屏幕图标进入即全屏、可离线。
- 提醒测试的朋友：练一阵后去「我的 → 设置 → 导出备份」发回 JSON。每位测试者只保留最新一份，然后用 `python3 scripts/summarize_backups.py 备份目录/` 汇总 D1/D7、校准完成率、系统分歧率和平均组时长。

构建、真机运行、Safari Web Inspector 和 TestFlight 上传步骤见 `ios/ShiziApp/README.md`。

## 重新生成题库

第一次运行前安装依赖：

```bash
python3 -m pip install -r requirements.txt
```

重新生成 `index.html` 内置题库、`generated/selected_8105_candidates.json` 和 `generated/hanzi_writer_coverage.json`：

```bash
python3 scripts/build_8105_chars.py
```

运行浏览器验证（会先执行 UI 文案门禁）：

```bash
node scripts/verify_8105_app.js
```

只做快速文案检查：

```bash
python3 scripts/verify_ui_copy.py
```

汇总测试者主动回传的备份（目录中每人只放最新一份；加 `--json` 可输出机器可读结果）：

```bash
python3 scripts/summarize_backups.py /path/to/backups/
```
