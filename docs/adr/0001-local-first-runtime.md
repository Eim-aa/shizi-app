# ADR 0001：保持无构建的本地优先运行时

- 状态：已接受
- 日期：2026-08-08

## 背景

拾字当前同时以静态 PWA 和 iOS WKWebView 资源包运行。核心记忆、手写、照片和练习事件只保存在本机；iOS 构建脚本直接同步同一套 Web 文件。项目尚处测试阶段，现有两套浏览器回归和原生 smoke 都依赖这些文件可直接执行。

## 决策

现阶段不引入 Vite、esbuild 或模块化迁移。第三方脚本固定在仓库中，页面不访问 CDN；Service Worker 对壳资源采用网络优先，对笔顺数据采用缓存优先和后台刷新，并把笔顺缓存限制为 800 项、永久保护核心 600 字。

Release iOS 包不包含破坏性 native smoke 脚本。Debug smoke、用户数据、临时分享文件与外部授权分别由编译条件、存储门禁、完成回调清理和发布清单约束。

## 后果

- 优点：PWA 与 iOS 继续共享同一可审计资源，离线行为稳定，不新增供应链和构建产物差异。
- 代价：`deck-data.js` 仍需一次性解析，主脚本仍是大作用域，首屏和可维护性问题没有被本 ADR 宣称解决。
- 触发复议：老机型出现可复现的白屏/Jetsam、首屏性能成为测试阻断，或模块边界改造进入正式排期。届时先评估按字库分片，再决定是否引入构建系统。
