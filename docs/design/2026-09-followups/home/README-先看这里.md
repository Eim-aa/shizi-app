# 拾字首页增量优化 · 纠偏轮

本交付直接以 `PR172` 原首页为基线，只做局部增量优化。此前的方案 A、方案 B 及其选择结论全部作废，没有被混合或沿用。

## 先看什么

1. 打开 [原版与修改版对照原型](./prototype.html)。
2. 用顶部三个状态切换：当天尚未开始、存在未完成组、今天完成一组。
3. 默认显示 ①②③ 三处改动标注；点击“显示改动标注”可关闭，查看无标注的真实视觉效果。
4. 阅读 [增量设计说明](./增量设计说明.md) 与 [复核清单](./复核清单.md)。

## 本轮只改三类位置

- 两行状态标题。
- 大朱砂印下方的一行简洁动作说明；续练态另保留一行必要事实。
- 原记录区名称与零记录显隐；“今日一字”暂时移出首屏，不新增替代模块。

## 本轮三个真实示例

- **尚未开始：**下一组是 6 个到期复习字。原版“一组”改为真实“六个字”；普通 15 字新组的原标题完全不动。
- **未完成组：**上次那组练到这里；`本组 6/15 · 2 个字会再出现`。
- **完成一组：**今天练过 13 个不同汉字，但不表示 13 个全部写对或掌握。

## 本轮有意不做

- 不修改 `PR172` 项目代码，不进入开发。
- 不画其余三态、深色模式、完整动效或全量尺寸。
- 不新增卡片、行笺、Logo、图标导航、练习示意或永久教学文案。
- 不重做“今日练过”字块，也不为移走“今日一字”填补新的内容；当天零记录时整个记录区隐藏。

完成态的原版没有产品经理提供的实际截图，因此左侧画面严格依照 `PR172` 固定快照中的 `renderHome()` 和原首页样式还原；另外两态同时参考了真实截图与固定代码。
