# 首页增量优化 · 复核清单

## 范围门禁

- [ ] 只存在一套修改方案，没有 A/B、混合案或延续旧方向。
- [ ] 三态均为同数据、同视口的原版 / 修改版并排对照。
- [ ] 三态都能通过 ①②③ 找到实际改动位置。
- [ ] `PR172` 固定快照没有被修改。
- [ ] 未提前展开其余三态、深色模式、完整动效或开发实现。

## 视觉连续性

- [ ] 关闭改动标注后，第一眼仍是原来的拾字首页。
- [ ] 页面没有卡片、行笺、Logo、英文品牌、导航图标或永久练习示意。
- [ ] 日期、竖题记、标题、165px 印章、有记录时的记录区和底栏仍在原构图位置。
- [ ] 米白 / 墨 / 朱砂与宋体 / 系统字 / 楷体关系没有改变。
- [ ] 留白没有被说明、数据块或组件填满。

## 三态理解

### 尚未开始

- [ ] 能看出下一组是 6 个到期复习字，而不是 15 个或未知数量。
- [ ] 印章下方只出现一次动作“开始复习”，没有重复数量或操作教程。
- [ ] 首屏没有“今日一字”第二个同权入口。
- [ ] 当天零记录时，整个“今日练过”区域隐藏，不出现标题、容器或空提示。
- [ ] 普通新练习仍使用原版“今天拾十五个字”。

### 未完成组

- [ ] 能说出“上次那组 / 练到这里”，且文案没有欠账感。
- [ ] 能复述 `本组 6/15 · 2 个字会再出现` 中的两个真实信息。
- [ ] 印章下方动作只写“继续练习”。
- [ ] 今日累计没有压过当前组状态。

### 完成一组

- [ ] 能说出今天已可以停止。
- [ ] 不把 `13 个不同的字`理解成 13 个全部写对或掌握。
- [ ] “再”仍保留，动作只写“想继续，再写一组”，没有操作教程、新强按钮、呼吸动画或催练语气。

## 文案与数据口径

- [ ] 页面没有把练过称为掌握、找回或拾得。
- [ ] 短复习数字来自实际下一组目标数，不直接使用可能大于 15 的总到期数。
- [ ] 续练分母来自保存会话中的真实不同目标数。
- [ ] 续练分子来自本组已经产生首次练习结果的不同目标数。
- [ ] 写错、不会写、看过提示和独立写对都可进入“今日练过”；纯跳过不计。
- [ ] 完成一组不等于全部写对，也不等于所有到期字清零。

## 后续实现前的最小可访问性门禁

- [ ] 可见动作说明不少于 14px；真实进度不少于 13px。
- [ ] 关键小字在宣纸色上达到 4.5:1 对比度。
- [ ] 印面及关联说明共享清晰的点击关系，命中范围不小于原 165px 印面。
- [ ] 三态读屏名称分别包含“开始复习”“继续练习”“想继续，再写一组”，并同步必要组量或进度，不残留被删除文案。
- [ ] 状态不依靠颜色、印文或动画单独区分。

通过定义：不熟悉产品的人更容易明白；熟悉产品的人几乎感觉不到首页被重新设计，只觉得更顺手、更诚实。
