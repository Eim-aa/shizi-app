# 品牌字「拾」· 定稿矢量母版（v2）

2026-10-05 第二轮（v2）。按验收意见在同一套 tools 上再修一轮，上一轮原样存在 `v1/` 里（文件、检查图、脚本都在），方便对照。v1 是 2026-10-04 做的。骨架用 **A1 端正楷书**（`brand/gen-brand-shi.mjs` 的 `skeletonKai`），App 内用 A1 墨重，图标用同一骨架加粗到 A3 墨重，87px 及以下另用光学加粗版。按 D33，图标和品牌字都只用一种墨色，不再把提手旁做成暖墨红。

**没有用任何字体文件的轮廓**（霞鹜文楷、华文楷体、Arphic 等都没碰）。每一笔都在 A1 骨架上用三次贝塞尔直接画出来。

## v2 这一轮修了什么（按验收意见的优先级）

1. **提穿出竖钩的小刺**：提的二次中心线在「竖钩右缘 − 2」处截断（`build()` 里用二分法求交点），提尖收在竖钩右缘以内。三种墨重下竖钩右侧都不露楔形。
2. **竖钩的钩**：重写成短而厚、与竖身一体的钩。左缘直着下来，在内角用小圆弧转进钩的上缘（直，约 35°）；下缘从竖底外凸着往上（约 65°），锋角约 30°，钩轴约 45° 朝左上。从内角到钩尖长约 0.7 个笔宽。试过 0.8，A1 墨重下又显细，所以取 0.7。v1 的钩是一根细长的针，现在没有了。
3. **横的起笔**（扌的横、合的两横）：去掉向左下伸出的尖喙，改成藏锋的方顿。起笔是约 50° 的圆钝斜切，两个角都用小圆弧收住，下角不再垂成钩。收笔右肩从 1.3 倍笔身降到 1.14 倍，下按从 1.3 降到 1.16。
4. **撇在 bold 下楔形、头重**：起笔头收窄约 15%（斜切宽 0.78、右肩外鼓从 1.3 降到 1.08、锋尖内收），中段右缘从 0.97 收到 0.9。宽度走得更匀，收锋仍尖。
5. **口**：横折直接从左竖起笔的角点起，用同一半径的圆角，横的上缘和左竖顶齐平，凹口没有了。折肩外耸从 1.4 降到 1.2，并用圆弧转向右下，更含蓄。
6. **bold-small 的捺脚上缘**：硬折点换成圆弧（半径 0.45 个半笔宽），三种墨重都柔和了。
7. **整体气质**：除撇、捺、钩、提的出锋锋尖外，所有端点都用两个锚点画成小圆弧：横起笔、竖和撇的起笔角、提的起笔、口的左上角、折肩、捺脚上缘。没有尖喙、尖角，也没有台阶。锚点因此从 61 增加到 71。
8. **光学**：图标里字的墨迹包围盒长边占画布 66%（676×544，v1 是 80%）。水平方向取墨框中心和墨迹重心各一半，放在 512。垂直方向让墨迹重心比几何中心高 1.5%（实测重心 y = 496.8）。小尺寸版长边占 70%；可遮罩版和浅色图标同样大小，最远点距中心 363（安全圆半径 409.6）。

## 六个问题怎么修的（v1）

| # | 问题 | 修法 |
|---|---|---|
| 1 | 人字头撇收笔处多出一根细丝（在撇捺交界的左下方） | 细丝其实是捺的起笔尖露到了撇外面。现在捺的起点退到撇身里面（起点向撇内收 6，整体下移约 20），捺尖完全藏在撇里，交界只剩一个干净的内凹。撇末段两条边近直线收拢成锋，不再拖丝 |
| 2 | 竖钩底部是锯齿缺口，没有向左上出钩 | 竖身右下角先圆转（蹲锋），这里也是全笔最低点。钩的下缘从这里斜向左上，略外凸；钩的上缘和竖的左缘之间用小圆角转过去，不留死角。锋尖朝左上约 40°，伸出竖身约一个笔宽。墨重加大时钩按比例加长，免得被吃掉 |
| 3 | 提的起笔扭曲，尾部过细且变细得突然 | 起笔改成左上锋尖加左下圆踵（向右下按笔的形状）。上下两条边各有一个中段锚点，控制宽度从约 0.8 个笔宽匀速收窄，尾段两边近直线收拢成尖 |
| 4 | 口的转角和左竖起笔处有毛刺、台阶，两个下角有多余的圆疙瘩 | 左上角：横折的起点放在左竖起笔斜切线 32% 处，横的上边从斜切线上自然长出，左竖锋尖露在左上；左竖的右肩被横盖住的部分不再外鼓，所以内角没有台阶。右上角：横的上边抬到折点后向右下斜切，再圆顺地接进竖的右边。两个下角：左竖和横折的竖都伸出底横约 15，收笔只圆收，不超出笔身宽度。底横两头都藏在竖里 |
| 5 | 轮廓是密集折线（几百个点），放大后有棱角 | 不再走「扫笔 → 栅格 → 等值线 → 折线」的流程。每一笔直接用 5–10 个锚点画成三次贝塞尔闭合轮廓，平滑锚点两侧切线共线；只有锋尖、钩尖、折肩和内角这些本来就该尖的地方用角点。整字 **61 个锚点**，旧候选有 354 个折线顶点 |
| 6 | 横起笔的「顿」像圆球贴上去，和笔身衔接生硬 | 起笔是左上锋尖加左下圆踵，收笔是右肩微微耸起、向右下按住。头尾都由上下两条边的弧线连续鼓出，笔身中段略细（腰）。收笔头高只有笔身的约 1.3 倍（旧稿约 2.2 倍） |

另外为了合乎法度，在 A1 骨架上做了三处微调：
- 口（含底横）以 (604,716) 为中心缩到 0.95，并整体右移 6、上提 6。这样口更小，落在人字头正下方，重心略往上。
- 口的左竖起点上提约 16，收笔下伸约 14。左竖露锋，并且伸出底横。
- 墨重加大时，扌整体左移、合整体右移（图标墨重下各约 10），给中缝留出空隙。A3 候选也做过同样的调整。

## 锚点数

v2 整字 71 个（v1 是 61 个，多出来的都是圆钝端角的弧点）。A1、加粗、小尺寸三种墨重的拓扑相同：

| 笔 | 横 | 竖钩 | 提 | 撇 | 捺 | 横 | 竖 | 横折 | 横 |
|---|---|---|---|---|---|---|---|---|---|
| 锚点 | 8 | 11 | 6 | 7 | 7 | 8 | 6 | 12 | 6 |

`tools/check.mjs` 对三种墨重分别检查：每条轮廓细分成折线后，非相邻线段都不相交（无自交）；轮廓都是顺时针（整字按非零规则填充）；最短的段长都大于 3 单位。三种墨重全部通过。另外，同一段两根控制柄长度之和不超过弦长的 0.8，避免墨重加大后控制柄交叉、轮廓起波。

## 图标的大小和位置（v2）

- 大小：墨迹包围盒长边占画布 66%，按验收要求的 64–68% 取中。浅色、深色、着色版的墨框都是 676×544，缩放 0.811；旧图标是 780×744，v1 是 824×670。
- 光学居中：水平方向取墨框中心和墨迹重心各一半，放到 512。只按墨框会偏右，因为捺脚和提尖是细锋，视觉上轻；只按重心会偏左，因为扌的竖钩最重。垂直方向让墨迹重心比几何中心高 1.5%。
- 小尺寸版长边占 70%（缩放 0.841），墨面积 12.9%（浅色大图 10.6%）。可遮罩版与浅色图标同样大小，整字落在安全圆内（最远点 363）。

## 重跑

```bash
cd brand/final/tools
node build.mjs     # 生成全部 SVG、strokes-final.json、tools/metrics.json（会先跑几何自检，不通过就报错）
node sheets.mjs    # 生成 check/*.png（用主仓库 node_modules 里的 playwright）
node check.mjs     # 只跑几何自检
node zoom.mjs 1.1 out.png 1   # 调试：15 处局部放大，最后一个参数为 1 时画出锚点和控制柄
```

改字形改 `tools/glyph.mjs`：`skeleton()` 是骨架，各笔法函数是笔形，`build(k)` 里是各笔的笔宽，`k` 是墨重（A1 = 1.1，图标 = 1.7，小尺寸 = 1.95）。`strokes-final.json` 的时序和压力取自 A1 候选的合成书写（`../out/strokes-A1.json`），按「第几段骨架 + 段内弧长比例」映射到定稿骨架上，只取了 t 和 p，没有取轮廓。

## 残留问题（v2）

1. **提不再穿出竖钩**。这和传统楷书扌「提尖穿出竖」的写法不同，是按验收意见取的取舍：安静优先于法帖原样。
2. **口的两个下角**：左竖和横折竖的收笔圆收略大，bold 下看起来像圆头。不鼓出笔身，但还不算方钝。
3. **捺脚**：捺的出锋仍是全字最锐的地方。这是捺本身的出锋，按要求保留。
4. **竖的起笔**：竖钩、撇、口左竖的起笔仍有右肩外鼓（顿），bold 下比较明显。这是楷书法度，没有再削。
5. **钩长**：取约 0.7 个笔宽，比验收建议的 0.8 略短，原因见上面第 2 条。
6. **书写回放**的时序和压力沿用 A1 候选的合成曲线（240Hz 合成，非真人）。阶段 2 如果请书家实写，应该换成真人数据。`curve` 的 v 已换算成 1024 单位/毫秒，和 `glyphs.js` 原来的模型单位不同。
7. **整字是九条重叠的路径，没有做布尔合并**。用非零填充和同色叠放，渲染没有接缝。如果以后要用描边或半透明（例如淡墨），需要先合并成一条外轮廓，否则重叠处会变深。
8. 这一稿只是在骨架上做的程序化精修，还**不是书家实写**（D33 说品牌「拾」由书家书写）。它可以作为上架用的过渡母版，也可以作为请书家写的参考。
