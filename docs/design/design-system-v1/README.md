# 拾字设计系统 v1（D33，2026-10-03 定稿）

设计源头：Claude Design 项目「拾字设计系统」https://claude.ai/design/p/97493147-d024-4bc3-92fb-f73a8861234f （规范页 `设计系统.html`、四屏对照 `关键页对照.html`）。产品负责人 2026-10-04 按推荐定稿（decisions.md D43）。

本目录是工程导入用的快照，改值先在 Claude Design 改、再同步到这里：
- `tokens.json`：机器可读令牌（颜色浅/深、字阶、字体栈、间距、圆角、线、阴影、触控、动效、材质、印章、组件尺寸）与 `mapping`（现行 src/config/tokens.css 变量 → 新令牌）。
- `shizi.css`：令牌的可运行镜像（设计稿用）。
- `设计说明.md`：设计决策与理由（对应审查 V/G 编号）、与第十稿差异、需真机验证的点。
