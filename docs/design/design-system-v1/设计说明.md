# 拾字设计系统 · 第一版

2026-10-03。对应决定 D33（视觉系统重建），为后续 D28 / D30 / D31 / D34 页面稿打底。取代第十稿视觉规格中相应部分；第十稿的流程、文案、术语不变。

## 设计决策与理由

1. **三种颜色职责：纸负责秩序、墨负责字、朱只负责批改与印章。**朱只剩两个用途：写错的朱点、落款与品牌的印；一屏最多两处。主按钮、选中 tab、今天、题面目标框、田字格线、焦点环、日期角标七处全部离开朱色。理由：第十稿同一个 #A6533F 身兼十职，写错的点和「写好了」按钮同色，批改的语义被稀释。〔V07 · G27 · DQ8b〕
2. **主按钮是实心墨、纸色字；次按钮是透明底 + 1pt 墨四边（≥ 3:1）。**首页主按钮宽 240 居中，流程页满宽：首页是一张纸，今天写的字要比按钮重。按下：缩放 .97 + 加深。〔V07 · G31〕
3. **淡朱是描红本的颜色，只用于提示和描一遍（D49 ⑤：自选未写的双钩改用 ink4，朱色只表示写错）。**与朱在明度上拉开（浅色淡朱更浅、深色淡朱更暗，始终「更靠近纸」），与本人墨之间 ≥ 3:1，色盲和灰度下靠明度与形状（笔画 vs 圆点）区分。提示叠在本人墨下层，本人墨不变暗。〔V03 V07 · D34 · DQ9〕
4. **深色是独立设计的「夜间纸」，暖黑不是反色。**纸 #1B1814、笺 #24201B、分组面对纸 1.26（≥ 1.25）；本人墨是暖象牙 #E6DAC4，参考字是偏冷的印刷墨 #B8AE9F，提示、描红、朱各自单独定值。深色主按钮用略压暗的月白 #E2D9C9；浮条（Toast / 撤销条）用夜间弹层面 #2A2520，不反色，避免夜里出现一块亮斑。暖灯、叶影取消。〔V08 · G28 · DQ8d〕
5. **磁青纸泥金只作对照稿。**规范页里给了一张静态平涂的候选（`.t-cyan`），不做颗粒和陀螺仪高光。〔V08 · DQ8d〕
6. **字体职责写死：楷只给「字」，宋给标题 / 数字 / 落款 / 题记，黑给操作与说明；拼音一律黑体。**练习字一律用 hanzi-writer 轮廓（题面、参考、墙、字帖、图片同源），ShiziKai 只做轮廓缺失时的回退。〔V02 V06 · G26 · D33 · DQ8a/c〕
7. **七级字阶 11 / 13 / 15 / 17 / 22 / 28 / 34，未微调。**相邻两级比约 1.15–1.3，「说明 → 正文 → 节标题」逐级可辨；不用 iOS Title3 20。行高：段落约 1.5 倍（中文需要），标题级 1.24–1.36 倍。字号全部乘 Dynamic Type 连续倍率 --k；AX 档单独排版。〔V06 V13 · G26 · D29〕
8. **中文不加字距（竖排题记 .2em 除外）；日期界面统一「10月3日」、纸面落款用汉字；数量 2 写「两」；说明句按小句断行。**〔V06 V17 · D36〕
9. **三档圆角：作品 0、控件 12、容器 24。**写字的纸、对照卡、字帖、印都是直角——它们是「物」；能按的是 12；从底部升起的是 24。真机用连续曲率。〔V19 · G26〕
10. **用留白和发丝线分组，不用卡片。**浅色当不得不有面时用「凹」（对纸 1.18）——浅色纸上做不出 1.15 的「更亮」卡片（理论上限是纯白），所以面往下沉而不是往上浮。〔V19 · G31〕
11. **格线归「纸」：印刷赭灰外框（对笺 3.14）+ 淡十字虚线。**外框标出「在哪里写」，按控件边界要求 3:1；十字是参照层。默认不画米字斜线。〔V07〕
12. **书写格 clamp(258, min(屏宽 − 40, 可用高), 400)，内部 345 单位；撤销 / 清空放在格下工具行右侧。**审查建议把工具放进格内右下角；我改到格外紧贴下沿：乚、捺、钩都收在右下角，放在格内会被误触或盖住笔画。位置仍然「所有尺寸同一处」。〔V11 V12 · D36〕
13. **页边 20，文字、格子、按钮共用一条边。**审查建议格子用 16；20 让所有元素对齐在同一条竖线上，402 宽上格子从 370 变 362，代价很小。〔V11〕
14. **主操作行位置跨页一致。**写字页「写好了」、判断页「写错了 / 写对了」、结果页「回到首页」在同一行（下方预留 44 的文字行），点完「写好了」拇指不动就能判断。格子与按钮之间的留白是收笔缓冲。〔V11 V12 · D20〕
15. **写错只多一颗朱点，不画朱圈。**直径 clamp(5, 格宽 × 0.07, 8)，按墨迹外框右上外 2pt 放置；结果页、字墙、判断动效同一个符号。〔V04 V14 · D30〕
16. **字墙只用一种新旧编码：墨色深浅四档**（相当于 1 / .82 / .68 / .55，四个独立色值，对纸 13.9 / 8.1 / 5.2 / 3.5，对数等距）。写错不再改字色和大小；自选未写用淡朱双钩（由轮廓生成，不用 text-stroke）。〔V14 · G30 · D36〕
17. **没有墨的格画衬底参考字，不写「没有笔迹」。**〔V16〕
18. **纸纹只在笺面**（书写格、对照卡、字帖、图片），页面底、按钮、弹层都平。占位只有细颗粒一层（低频云絮层读作水渍、还会烘进导出图，D51 ⑥ 起删掉；导出图用平涂笺色），去掉了第十稿 7 / 11px 规则点阵（摩尔纹）和我第一轮尝试的方向性纤维层（深色下像扫描线）。真机换扫描资产。〔V09 · G29〕
19. **印章白文「字」、方形直角，尺寸只有 16 / 24 / 40，只在落款与品牌处，一屏一枚。**〔V10 · G29〕
20. **外壳交给原生**（UITabBar、UISheetPresentationController），只设颜色与字体；设计稿不模仿玻璃。〔V18〕
21. **文字按钮只有一种：黑体 15、ink2、无下划线，按下变 ink1；「›」只跟在去处的名字后。**可点性靠位置（行尾、底栏）与动词文案，不靠下划线；标签是去处名（回到首页、练习记录、还有 N 个字）→ 带「›」，标签是动作（撤销、取消、提示、看答案、跳过、自己选字、练这些字、保存图片）→ 不带，也不用「→」。文字按钮保持 44 点击区，用负外边距把字形外缘对到 20pt 页边线（页头尾端、文字按钮、格子与主按钮共用同一条右边线）。〔T2-01 T2-02 · D51 ⑥ · H1〕
22. **实心深色填充只给每屏唯一的主按钮；L4 浮条是「浮起的浅面」。**撤销条、失败提示条、Toast 原来是 toast-bg（= 主按钮的墨色）实心、12 圆角、满宽，和最下面的主按钮同色同形，真机上被看成又一个主按钮、和真正的主按钮抢视线。改为 elev 面 + 1pt line 细边 + 轻阴影（shadow.toast），正文 ink1，「撤销」等操作是 500 字重的文字按钮（toastAct = ink1，无下划线），倒计时细线 ink3 40%；圆角取容器档 24（最小高 48 时就是胶囊），与 12 圆角的按钮在形状上也分开。选「大一级圆角」而不是另起胶囊令牌：不新增圆角档，浮条与弹层同属浮起的面。浅 / 深两套 toastBg 对 btnBg 的对比度分别是 15.0 / 10.8（门槛 3）。与 Apple HIG「一屏一个突出按钮」一致。〔D71 ③〕

## 尚需真机 / 真人验证

- **纸纹在 OLED 上的可见度**：深色笺面的细颗粒在 OLED 低亮度下是否像脏斑（云絮层已删）；浅色颗粒在 True Tone / 户外是否完全消失。方法：真机室内灯、日光、最低亮度各拍一次。
- **字墙四档新旧能否分辨**：第三、四档（5.2 / 3.5:1）在小字（45pt）上可能分不开。方法：让用户在墙上找「一个月内写过的字」，记正确率与用时；不行就降为三档。
- **淡朱与朱在真实屏幕上的区分**：亮度比只有 1.6（浅）/ 1.6（深），靠「笔画 vs 圆点」的形状和出现场合不同来区分。方法：真机系统色彩滤镜（红 / 绿色弱）下看写字页提示与结果页朱点。
- **深色墨是否仍像粉笔**：暖象牙 + 提按应当改善，但取决于 V01 的真笔模型（湿墨 / 干墨）。
- **答案衬底 3.2:1 在户外是否看得见**；描一遍双钩在 6.1 寸屏上是否太细。
- **格框 3:1 是否与细笔画抢戒**：尤其是写到格边的长横。备选：外框降到 2.6:1、靠笺面纸纹补充边界。
- **首页 240 宽主按钮**的可发现性和单手可达性（Pro Max）。
- **竖排题记**在 PingFang / Noto Serif 下标点的竖排形和位置。
- **动态字体 AX1–AX5** 的整套版式（本版只给了规则，没有画 AX 稿）。
- **hanzi-writer 轮廓作为全 App 唯一字形**的授权（Arphic Public License）需法务确认；墙与字帖需预生成轮廓子集，包体与渲染性能待工程实测。

## 需要产品负责人选择

1. **首页「拾」品牌放在哪里。**第十稿的「拾」方块既是品牌又是主按钮；本版按 D33「主按钮改墨色」和 V15 把它拆掉了，品牌只剩启动、图标和题记旁的印。如果希望首页仍有「拾」字，可选：A 主按钮左侧加 22pt 墨色「拾」；B 首次 / 无记录时字帖位放书家「拾」；C 不放。推荐 B。
2. **格内 vs 格下工具。**审查建议撤销 / 清空在格内右下角，本版放在格下（理由见决策 12）。如果更看重「一只手不移动」，可改回格内。
3. **页边 20 vs 16。**见决策 13。
4. **判断页对照卡的位置。**本版放在题面与按钮之间的视觉中心；另一种是与书写格同一顶边（内容偏上、下方大片留白，但 D30 的「墨缩进左卡」动作位移最小）。等 D30 动效稿一起定。
5. **磁青纸泥金是否进入 T3 / T9 真人测试。**

## 已知局限

- 本版只重绘四屏，字库、我的、设置、查字等页面由后续页面稿用本系统绘制。
- 图标是临时画的线性占位，真机用 SF Symbols；状态栏是示意。
- 「拾」和印是第十稿的霞鹜文楷占位，待书家与篆刻。
- 动效只定了按下态；判断、收字、归位成帖的动效属于 D30 稿。
