## 常用入口

打开单文件原型后，在地址后面加参数：

- `?flow=2.1&phone=1`：第一次来，写 5 个字到第一次结果页。
- `?flow=2.9&phone=1`：今天已有记录；从“我的 → 练习记录”可以看 9 月字帖和这次的图片。
- `?flow=10.1&phone=1`：字库首页、自选的字、单字详情。
- 原型右侧（或下方）的场景面板可以切手机尺寸、“更大字体（紧凑版 360×640）”、有 / 无记录等状态。场景面板是原型工具，不进产品。

## 不在本目录的源文件

组件、两张画布（主要页面、全套页面）、字库探索画布、笔迹管线 `ink-第十稿交接版.js`、演示数据 `proto-model-第十稿交接版.js` 等源文件在设计项目里，由产品负责人持有。交接备注开头列了完整文件清单。文档里提到的《第十稿-进度》《第十稿-简报》等也在设计项目里，需要时向产品负责人要。

快照的核对方式：12 份快照和对应工作文件逐字比对，只差引用名、`<title>` 和页头；全部引用都指向快照文件；上表 sha1 与设计师给的值逐个重算一致。第七、八、九稿的旧快照都没有改动。

## 验证过什么、没验证什么

内部验收员在桌面 Chrome（Playwright，393×852 与 360×640 更大字体两种尺寸）实际跑过：第一次来的 5 个字到结果页（含看答案、跳过、写错）、字库与单字详情、移除自选再撤销、更换字库、备份替换 / 撤销 / 清空、9 月字帖与这次的图片的入口，快照版和单文件包都跑过，控制台没有错误。

没有覆盖：Safari / WKWebView、iPhone 真机手感、Apple Pencil、读屏、弱网。这些按 [交互验收检查表](../../product/03-interaction-handoff-checklist.md) 和交接备注在接入时另行验证。
