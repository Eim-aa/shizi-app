## 二、四个交互缺口

- **10.10** “结束这组”：写字页下方跳过那一行的右边（只在这次选的字里）；确认；有判断 → 结果页“这次选的字 / 结束了”，零判断 → 回来源 + 底部说明；结束时保存失败按 2.6，重试成功后结束。
- **10.11** 写错过 / 快忘了 / 卡片 / 红点 / 单字详情那一行都由 `SZProto.lists()` 按记录算；深链三条演示。
- **10.12** 记录字段 `ink`（none / shape）；状态 2 画黑体字 +“没有笔迹”（大格“这一次没有留下笔迹”）；手写字图片要最近一次有笔迹，否则那一行置灰说明；本次 / 本月图片只画有笔迹的字，落款字数跟着减，说明写出不在图里的字；都没有时结果页换成说明。场景面板“笔迹缺失的样例”。
