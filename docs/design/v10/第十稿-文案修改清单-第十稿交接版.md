## 零、统一口径

- **保存失败**：说明句“没保存上，{什么}还在。”（按情况换词）；主按钮一律“再试一次”，次按钮“先不 + 动作”（先不保存 / 先不换 / 先不加 / 先不选）。
- **撤销**：一律“离开这一页前可以撤销”。
- **快忘了**：说明“有一阵没写、可能快忘了的字。”；单字详情那一行“有一阵没写，可能快忘了”。
- **看过答案**：“这个字记为看过答案，后面再写只算练习。”；下一个字顶上“「X」记为看过答案”（收尾 X10：字加「」，结果词不加引号）；结果页“跳过和看过答案的字不算在内。”。
- **结果行**：“「X」记为写对 · 修改 ›”，改过是“「X」已改为写对 · 修改 ›”。
- **字库数量**：换库列表“可以练 {N} 个字 · 有记录 {M} 个”+ 底部来源说明；字库首页练习范围一行只写库名。
- **备份**：状态和日期一律说“备份”（上次备份 {日期} / 还没有备份 / 现在的记录都已经备份了 / 上次备份以后记录有改动，还没有备份）；按钮“导出备份文件”不变。
- **开新组弹框**：“上一组还有「鲜」「境」没写。”按钮“接着写那组 / 结束那组，开新的 / 取消”。
- **图片**：这次的图片 / {月}字帖 / 手写字图片；入口“把这个字做成图片”。
- **数字**：界面一律阿拉伯数字，代码里把 cn() 转汉字数字的地方都改掉（月份天数、记录次数、年度报告等）；只有纸面落款保留汉字数字（二〇二六年九月 · 有记录二十二天 · 八十个字）。引号一律「」。
- **叫法**：设置（原练习设置）、外观（原深色）、练习范围（设置里的字库行）、按键音、这台手机、换掉这个词语、小学初中常用字（原义教基础字）、结束这组（不改）。
- **待工程确认、确认不了就删**：D6 结果页“这组字难不难”和第一次结果页“以后写哪些字，会参考这次的结果”；D7 单字详情“下次练习 · 大约 X 日再练到”；D10 设置里“手写字图片提示”。
