# 拾字 · 第十稿边开发边改清单

2026-09-30。第十稿冻结时交给工程。这里列的都是**不改流程、不改数据、不改页面结构**的小问题：文案、视觉、小交互。工程先按冻结稿做，做到对应页面时顺手改掉，不再回到设计稿里改。

来源：
- **走查 B 类**：《第十稿-走查问题汇总》（uploads/走查/）里的 B 类 37 项，已在第十稿做掉的不再列。
- **冻结前最后一次复验**新发现的小问题（第一节）。收尾复验的 Y01–Y07 已在原型里改好，不在这里。

冻结后再发现的同类问题，也一律加进这份清单，不再开设计轮。只有流程走不通、会丢数据、会误导用户三类问题，才回到设计。

## 一、冻结前复验新发现的

| # | 问题（原型现状） | 改法 |
|---|---|---|
| Z02 | 写错过 / 快忘了清单一个字都没选时，“先选一个字”看着是灰的、点了不动，但没有标成不可用（没有 disabled / aria-disabled，鼠标仍是手形），读屏会念成能点的按钮 | 正式版用真正的禁用状态 |
| Z03 | 紧凑版单字详情撤销时，“已撤销”盖住“从自选的字移除”的副标题约 2.4 秒（不压“练这个字”，点击不会穿透） | 提示不盖文字，或者放在不挡内容的位置 |
| Z04 | 紧凑版备份页撤销后页面自动上滚，让出“清空所有记录”，大号日期被标题栏切掉上半截 | 正式版用原生底栏和安全区排版，不靠自动滚动让位 |

## 二、写字页

| # | 问题 | 改法 |
|---|---|---|
| W16 | 跳过没有反馈，不能反悔 | 跳过后底部轻提示“已跳过「警」 · 撤销”，3 秒 |

## 三、几种“组”、字库、查字

| # | 问题 | 改法 |
|---|---|---|
| S04 | “结束这组”确认框里，放弃是醒目的主按钮 | 主按钮是“接着写”，“结束这组”用普通按钮（开发时对照原型确认） |
| S05 | 从写错过、快忘了开的组，结果页没写来源 | 结果页按来源写“从写错过 / 从快忘了 / 自己选的” |
| S06 | 清单写到一半返回，勾选被重置成全选；没有全选 / 全不选 | 返回时保留勾选；加“全选 / 全不选” |
| L04 | 查字 → 练这个字 → 返回，查字结果没了 | 回到查字卡片，输入不变（开发时对照原型确认） |
| L09 | 字库首页大数字点了没反应；墙上只显示一部分也不说还有多少；快忘了空卡片看着能点 | 大数字可点进完整页；墙底写“还有 N 个字 ›”；空卡片去掉卡片样式 |
| L10 | 换完字库没有提示 | 换完轻提示（叫法、每个库的说明、练习范围一行只写库名，已在第十稿做了） |
| L11 | 有记录的字完整页：排序和筛选同时生效时看不清；数量为 0 的筛选也能点；按拼音排序时字上没标拼音；不能用拼音查 | 选了筛选后排序收起；0 个的筛选变灰；拼音分组里每个字标拼音；支持拼音查 |
| L12 | 单字详情：有一个空的“下一次”格子；有的字有部首字源，有的没有 | 去掉空格子；没有字源的字整块不显示（叫法已在文案清单改） |
| L13 | 历次笔迹点了不能放大；做图片只能用最近一次 | 点格子放大；做图片时可以选用哪一次 |
| L14 | 深色下“墨色越浅，越久没写”正好说反；最浅一档看不清 | 深色下改成“颜色越暗，越久没写”；最淡一档提亮 |

## 四、我的、练习记录、图片

| # | 问题 | 改法 |
|---|---|---|
| M03 | 300 个字时我的页字帖占满，菜单被挤到很下面 | 我的页只放字帖最近 3 行，加“全部 ›”（开发时对照原型确认） |
