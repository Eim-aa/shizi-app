# 拾字文案重写方案（只出方案，未改任何代码）

范围：`src/config/copy/*.js` 共 688 个槽位（与 `docs/engineering/v10/copy-source.json` 一一对应）。法律文书正文、字/词/拼音数据、开发日志不在内。

## 一、用到的原则

1. **一眼看懂（《Don't Make Me Think》）**：用户不该为一个词停下来想。凡要想一下的词（目标字、释义、书写格、判断、落款、卷首）一律换成日常说法。
2. **一个概念一个词**：同一件事全 App 只叫一个名字，不要「练习范围/字库/更换字库」「有记录/写过/记录了」混着用。
3. **名称短、描述简（《写给大家看的设计书》的去噪）**：名称（标题、按钮、菜单项、行名、tab、小标题）2–4 字；描述（说明、副标题、小字、提示、读屏）不超过 20 字，多出来的话直接删，不靠加字解释。
4. **按钮写结果，不写心情**：「开启提醒」比「好，明天给我一个词」「好」更清楚；取消类固定「先不…」。
5. **失败提示三件事**：出了什么事、你的东西还在不在、下一步做什么；沿用已有的「没保存上，……还在」句式。
6. **整句情感文案不动**：首页题记、首次练习标题、落款、年报封面句不别扭、不含术语，保留；只在上面列出的原因下才动。
7. **功能不改**：只改字，不改点了会怎样；带 `{n}`、`{date}` 等变量的保持原变量写法。

计数口径：不计空格、标点、`›`、「」、序号；变量按实际内容算（名称里的变量不计字数）。

## 需要负责人决定的问题

以下每题都已按「推荐」方案先写进上面的新文案；负责人选了别的选项，只需回改对应槽位。

### Q1 底部第一个 tab 叫什么？
tab 现在叫「习字」。「习字」是书法课用语，且与首页按钮「开始写字」、写字页并不统一。
- A（推荐）写字：最直白，与「开始写字」统一
- B 练字：口语，但「练」和「复习/练习范围」的「练」撞字
- C 保留习字

### Q2 练习范围的四个选项叫什么？
现在是「规范常用字 / 规范次常用字 / 规范专门用字 / 小学初中常用字」，「规范」「专门用字」像文件名，且超 4 字。
- A（推荐）常用字 / 次常用字 / 少见字 / 课本字（少见字比「专门用字」好懂；课本字 = 语文课要会写的字，是否贴切请确认）
- B 常用字 / 次常用字 / 生僻字 / 小初字
- C 保留原名，接受超过 4 字

### Q3 空状态标题能不能超过 4 字？
如「现在没有要写的字」「现在没有写错过的字」「你写下的字会留在这里」。压到 4 字只剩「暂无」「没有」，信息太少。
- A（推荐）允许空状态标题用不超过 8 字的短句（本稿已这样处理，已列在对应行的理由里）
- B 全部压成 4 字（如「没有要写的」「暂无字」），正文承担说明
- C 去掉空状态标题，只留正文

### Q4 「回到……」离开按钮可以超 4 字吗？
如「回到写错过」「回到该复习了」「回到写过的字」，是返回上一级的按钮，名称部分都 ≤4 字，加上「回到」才 5–7 字。
- A（推荐）允许，它是「返回」+去处，读起来是一个动作
- B 一律改成「返回」，去处不写
- C 改成「‹ 写错过」这种箭头加名称

### Q5 「写错过 / 快忘了」和 D60 的「该复习了 / 还不太熟 / 记住了」要统一吗？
字库首页已改成三档，但「全部」页的筛选和单字详情还保留「写错过」「快忘了」两个旧说法，二者算法是否等价我没把握（「快忘了」=有一阵没写；「该复习了」=到期或写错）。
- A（推荐）等你确认算法：若「快忘了」就是「该复习了」的子集，则全 App 只用三档名；本稿暂时不动这两处
- B 现在就把「快忘了」改成「该复习了」，「写错过」保留为筛选
- C 两套都保留，只修措辞

### Q6 存储出错的三段长提示（X-SYS.*）
原文 `blockMigration` 里有两句关键警告：「不要清理浏览器，也不要删掉拾字」，压到 20 字会丢。`corruptNotice` 也丢了「可用备份恢复」的指引。

- C 这几条保持原文，不受 20 字限制（它们是阻断页，不是小字）
