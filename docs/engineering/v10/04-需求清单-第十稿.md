### 5.3 其他坑

- 文案清单的行号对应"当时的文件"（文案 L3），已漂移；只能按原文查找。且原型单文件里组件模板是转义字串，**grep 不到组件文案**；核对只能在浏览器里点或向产品负责人要 `.dc.html` 源文件。
- 改动清单是叠写日志：同一件事最多出现在 5 个层（10.x → 走查 → V → X → Y/Z）。取规则时永远从最后一层往前找。
- 撤销寿命共有四种，不能共用一个计时器：备份页替换/清空 = 直到离开本页；单字详情移除 = 直到离开本页；跳过 = 3s（W16）；书写格清空 = 一次（W17）；"已撤销"提示 2.4s。旧 10 秒窗口（#173）全部作废（改动 L107）。
- 结果行是一个小状态机：显示条件 = 当前字处于回忆阶段 且 未落笔；隐藏触发 = 落笔 / 跳过 / 确认看答案；跳过后内容清空并只描述紧挨着的上一个字（X02）。
- 防连点必须用事件自身时间戳（备注 L158），否则 60/120Hz 与后台恢复下会漂。
- 备份页"保护副本"必须先落盘成功再替换（10.14）；撤销失败后撤销仍要可再点（10.15）；状态句按 `kind` 而非按文字判断。
- K03 记录数回归曾在走查出现一次、原型未复现（交接 L78）——排进自动化测试。
- Z01 的 `imgMode` 粘连 bug 说明图片弹层应由入口显式传入模式，不能靠残留状态。
- 字库四库的字数与"有记录 M"在原型是写死 `LIBS`，正式版必须逐库有字表才能算 M（备注 L90）。
- 演示数据里 300 字/9 月 1 日备份/8 月 12 日 5 个字都是假设值，不要当验收基线（备注 L93–95）。
- 落款是唯一保留 `cn()` 汉字数字的地方（文案 L16）；做一个显式的 `signatureNumber()` 而不是全局开关。
- 字体：子集要覆盖全部可练字 + 语境词 + 释义 + 字源；拼音声调组合字符（ê̌ / m̌）在宋体/黑体里不能掉（备注 L131；决定 L60）。
- `data/handwriting/格式-第十稿交接版.md`（备注 L16、L137）在仓库里**不存在**；真人笔迹录制格式无从对照。
- iOS：查字框 focus 要在点击处理里同步调（备注 L40）；页面切换和边缘右滑用原生（备注 L38）。
- 深色文案反向（L14）和对比度值（备注 L106）要一起进设计令牌，不要散在组件里。
- README L34–35：设计冻结只在桌面 Chrome/Playwright 验过，Safari/WKWebView、真机、Pencil、读屏、弱网全部未验。
