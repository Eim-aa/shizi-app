更新：2026-10-03。依据：[decisions.md D26–D36](../../handoff/decisions.md)、[ADA 汇总](ada-review/汇总-ADA差距与路线.md) 第 5 节阶段 1 与 G 清单。本阶段不依赖原生化；凡阶段 2 会由原生重做的（墨、写字流程编排、判断页），本阶段只交**规格与原型**，不在网页写字页正式实现（避免浪费，见汇总「哪些会被浪费」）。

## 2. 顺序

1. 立即并行：P1-D1、P1-E3、P1-C1、P1-S1（阶段 0 四张卡同时在跑）。
2. 阶段 0 合入后：P1-E6。
3. P1-D1 定稿后：P1-E1 → P1-E2；P1-D3/D4/D5/D6 依次出稿。
4. 字表审定后：P1-E4 → P1-E5。
5. P1-S1 初版后：P1-S2。
6. 真人测试：T3、T9、T6 基线在阶段 1 前半；T2、T8、T11 随原型；T7 在阶段 1 末启动（见汇总第 7 节）。

## 3. 验收

- 每卡：门禁全绿（`pnpm test`）+ 验收者审 diff + 模拟器截图前后对照（同机型、同数据、浅深、普通/大字）。
- 设计卡：产品负责人在 Claude Design 批注并标「定稿」后才进入实现。
- 阶段 1 出口：G03/G04/G07/G08/G09/G10/G26–G31/G33/G34 关闭；G01/G02/G24/G25/G35/G36 有定稿规格与原型；T3/T9 有记录（不填虚构数据）。验收记录写 acceptance/阶段1.md。
