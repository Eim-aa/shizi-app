# 写字流程确认单（原生化第②步开工前）

2026-10-21。原生化第②步要把「写字页、判断页、结果页」用原生重写。原生页面会照这份清单的流程来做；规则（出题、判断、复习间隔）不重写，直接运行现在的代码。请逐段看「现在是这样」对不对，最后回答「要你定的」几个问题。

## 1. 进入写字页

| 从哪里进 | 进来的样子 | 返回 |
|---|---|---|
| 首页主按钮「开始写字 / 继续写字 / 再写一组」、首页「接着写」那一行 | 纸从按钮处展开 | 纸缩回按钮（D62） |
| 字库「今日练习」、各档「练这些字」、字详情「练这个字」、查字「练这 N 个字」、结果页「再写一组」 | 从右边推进来 | 往右滑走 |

- 一组的字数按「我的 › 每组字数」（缺省 20）；首次练习固定 3 个字。
- 写到一半离开，下次「接着写」回到原来那个字、原来的笔迹。

## 2. 写字页（回忆阶段）

从上到下：
- 页头：左上「‹」返回；中间「7 / 20」进度；右上「跳过」，今天这一组和自选组在它左边还有「结束这组」。
- 题面：词语和拼音，要写的那个字是空格。
- 书写格：在这里写。
- 格子正下方：左「撤销」、右「清空」；清空后可以撤销一次。
- 格下一行说明位：显示上一个字的结果，例如「「拾」记为写对 · 修改 ›」，落笔后收起。
- 底栏：「提示」「看答案」两个按钮，下面是主按钮「写好了」（没写时不能点）。

规则：
- 左边缘右滑 = 左上「‹」，每个阶段都能用。
- 换字后 0.4 秒内按钮不响应（防误点）。

## 3. 提示（D64 ①）

- 每点一次，在已经给出的笔画后面再多给一段（约四分之一个字；没有部件数据的字每次一笔），可以一直点到整字出现。
- 你写过的那一笔，对应的提示笔会淡掉；撤销时会回来。
- 点到整字出现：按钮变灰，这个字算「看过答案」。
- 复习时用了 1 次提示写对，下次间隔缩短；用了 2 次及以上，按「没写出来」算（D66 ②）。

## 4. 看答案（D64 ②、D66 ①）

- 点「看答案」：标准写法直接淡淡显示在格子里，立即可以描着写（描一遍）。第一次看某个字时先快放一遍笔顺（不超过 1.6 秒，落笔即跳过）。
- 格下说明：「记为看过答案。」
- 底栏：主按钮「凭记忆写」，另有「下一个」。
- 点「凭记忆写」：答案和笔迹清空，凭记忆再写一遍（只算练习，不判断）；底栏变成「再描一遍 / 下一个」。
- 复习字看了答案，当天记一次「没写出来」，当天不再出现。

## 5. 判断页

- 点「写好了」进入判断页：上格是你写的，下格是标准写法；标题「写对了吗？」。
- 两个按钮：「写错了」「写对了」，由你自己判断。
- 左上「‹ 接着写」回到书写格，笔迹原样还在。
- 判断后直接进下一个字；上一个字的结果显示在格下那一行，「修改 ›」可以改判（只改这一次，不多算一次）。

## 6. 跳过

- 右上「跳过」直接生效，不确认；底部出现「已跳过「X」· 撤销」，5 秒内可撤销（手指按住暂停计时）。
- 跳过的字当天不再出现；新字推迟 7 天再出现。

## 7. 结束这组（D66 ⑥）

- 点「结束这组」：确认框「还有 N 个字没写，结束后就不写了。判断过的 M 个字已经记下。」，按钮「接着写」「结束这组」。
- 结束后：有判断过的字就进结果页；一个都没判断就回到来源页。

## 8. 结果页

- 写完最后一个字（判断、看答案后「下一个」、或跳过）直接换成结果页，没有中间页。
- 内容：本组的作品（你写的字排成字帖），落款与印；下面是「没放进图里」的字（看过答案、跳过的）和每个字「N 天后再见」。
- 点作品里任一个字：底部弹层对照你写的与标准写法；判断过的字可以「改为写对 / 写错」；「看这个字 ›」进字详情。
- 写错的那一行有「修改 ›」。
- 底栏：主按钮「再写一组」；本组有写错的字时还有「重写错字」。
- 出口：左上「×」。自选组的出口是「回到字库」等来源。
- 首次练习的结果页：标题「这三个字，很多人提笔就忘。」，下面问要不要开提醒（「开启提醒 / 先不用」）。

## 9. 重写错字（D66 ③）

- 结果页「重写错字」推入：逐个写本组写错的字 →「写好了」→ 对照（没有判断键）→「下一个」，最后一个是「完成」回到结果页。
- 只算练习：不记录、不影响复习、不存笔迹。

## 10. 原生后会自然变好的（不需要你定）

- 书写：原生触摸直接画，跟手更快；支持 Apple Pencil 压感、倾角（D32）。
- 页面切换、左滑返回、弹层：用系统的，手感和系统 App 一致。
- 大字号、读屏：用系统组件自带的支持。

## 要你定的

1. **判断方式**：保留「自己判断写对 / 写错」？还是原生后加自动比对（App 先给出建议，你确认）？我的建议：保留自己判断，自动比对另作评估（准确率不够时反而添乱）。
2. **看答案时的笔顺快放**（1.6 秒）：保留、去掉，还是改成点一下才播？我的建议：保留，落笔即跳过。
3. **跳过的撤销提示**（底部 5 秒「已跳过 · 撤销」）：保留？我的建议：保留，这是唯一能挽回误点跳过的地方。
4. **结束这组的确认框**：保留？我的建议：保留，结束后没写的字就不写了，误点代价大。
5. **以上 1–9 有哪里和你用起来的感觉不一样**，或者你想改的流程，直接指出段落编号。
