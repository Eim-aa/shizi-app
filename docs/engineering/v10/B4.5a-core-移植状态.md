- `api/settings.js reminder.plan` 传 `deckAdapter`，但它没有 `cardFor`。开启提醒且 sched 有合法、可练的 due 项时，真实 JS 返回 exception `deck.cardFor is not a function`；Swift 在同条件保留该回包。

- judged 已存在时只补会话推进，不新增记录/不重复评级。
