## 3. 浏览器走查（验收者，内置浏览器）

- 375×812：种 A 会话（永/聚/春）→ 写字页：题面「yǒng ▢ 远」、提示按钮「提示 · 还有 2 次」；点提示后画一横，提示收起、说明句带圆点、按钮变「还有 1 次」，会话 current.hints=1、strokes 1 条（编码行）。写好了 → 判断页：「接着写」文字键、两键样式一致、无预选。**刷新**：回到判断页，本人笔迹与参考字形都在。写对了 → 下一字，结果行「「永」记为写对 · 修改 ›」，records 1 条 judged（help.hints=1）。看答案 → 确认框（alertdialog，无预选）→ 看答案页播放笔顺 → 描一遍（先播一遍、描红层上写一横）→ 下一个 → 第三字跳过 → records 为 judged/answer-seen/skipped 各一条。
- **G1（阻断）**：360×640 打开写字页（无任何指针操作，nav.push 也一样）书写格顶部正中出现一个圆点，写好了变为可用，撤销/清空行可见；固化层 254 个非透明像素；375×812 下正常。
- **G3**：最后一字跳过后显示空页（`write-empty`），跳过的 3s 撤销底栏不可见；用户在下一字落笔后底栏仍在，撤销会丢掉已写笔画。
- 记录 id 从 r2 开始（r1 被什么占用未查；id 只要求唯一，不算缺陷）。
- 看答案页上结果行收起（进入看答案流程即收起），可接受。
