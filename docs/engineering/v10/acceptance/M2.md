## 3. 浏览器走查（验收者，内置浏览器 375×812）

- 首页首次态：日期行「10 月 1 日 · 晚上」、竖排题记「文章千古事，得失寸心知。——杜甫《偶题》」、标题、「拾 / 开始写字 →」、首次说明、「自己选字 →」、三 tab。
- 自己选字 → 底部弹层：标题、输入框、两行（永 yǒng 永远 / 和 hé 义和团，行尾「还没有记录 ›」）、说明句、底栏禁用 → 勾选两字 → 「练这 2 个字」→ B 会话 `queue [永,和] kind picked source home`，custom 未写。
- 写字页多了「结束这组」；写一横 → 写好了 → 写对了 → 第二字带结果行 → 结束这组 → 确认框（接着写为主键）→ 结果页 → 回到首页：`records=record resume=none`，墨迹行「永」，「今天记录了 1 个字」。
- **H1**：reset 后刷新，路由从 history 恢复写字页，但会话已空 → 空页只剩返回键与标题。
- **H3**：结果页格子按钮与查字行按钮无无障碍名。
- **H4**：「结束这组」只在 recall 阶段显示，看答案 / 描一遍阶段没有（原型除 finished 外都显示）。
- 第一次点「练这 2 个字」后 1 秒截图仍是首页，再截图已是写字页：转场时间内的截图，不是缺陷。
