## 5. 修复回合

| 项 | 复验 | 说明 |
|---|---|---|
| I1 ink v3 | 通过 | 每点 4 字节大端（x10/y10/w8/dt4，dt 16 档对数量化），p 仅 pen 每点 1 字节；`inkMaxPointsPerStroke=24`；14×24 一条 3732B，300 条 ≈1.07MiB；解码兼容 v2；schema 双版本 |
| I2 reclaim:false | 通过 | `store.commit(label, mutate, {reclaim, replace})`；backup.js 不再借 `store.seed`；替换经 `replaceWithBackup(mutate)`；store 26/26、backup 18/18 |
| I3 sessions 入保护副本 | 通过 | 替换/清空 A/B 置空、lastEnded 保留、原会话存 payload；撤销全键（含 sessions）深相等；42-backup 180 条 |
| I4 P77 | 通过 | `seenCurrentItem` 补一格不可改判；23-result 122 条 |
| I5 none 页更换字库 | 通过 | `setNoneActions({libSwitch})`；字库写完时为主按钮；21-session-start 87 条 |
| I6 图片入口口径 | 通过 | `inkPresent` 与格子共用；刷新后 allMissing |
| 附带 | 接受 | copy-source.json 补 P79–P90 的 nonRuntimeDecisions |
| 复跑 | 通过 | 验收者：verify:unit 502/502、verify:copy 515/515、42-backup、23-result、44-scenario；代理：verify:web 28 spec 3049 条 |

修复代理新发现：带压感的字约 4.7KB/条，300 条 ≈1.35MiB（低于 1.5MiB 预算、高于 1.2MiB 目标，记入 P78）；P77 补进的字仍算在「还有 N 个字没写」里（记入 P77 待文案裁定）；替换后 lastEnded 可能指向已替换掉的记录（M6 处理：替换/清空时一并清 lastEnded）；单测共享 `rememberInk` 缓存（M6 加清理接口）；none 页换库返回后不重新开组（记入 P83）。

**M3/M4 结论：通过。**
