## 3. 验收侧裁定与遗留

- **书写格预留高度校准**：预留 446/384pt 在 Chromium 量得、不含安全区。按公式 iPhone 17 约 352、iPhone 15 约 333（旧 345），Pro Max 封顶 400；高度跨 760 时边长跳变。写字页版式阶段 1 按新设计系统重排，校准并入该卡（P1-E1 之后的写字页改版），不单独出卡。
- **按压反馈未覆盖**：结果/详情/记录页的 `sz-rcell`/`sz-dcell`/`sz-scell` 是原生 `<button>`，首页 CTA 旧 `:active` 与新 `data-pressed` 可能叠加 → 随 P1-E1 token 导入处理。
- **逐提交可二分性**：卡 B 的 A2、A9 两个提交各自漏登记白名单，在后一提交补上，单独检出这两个提交时 verify:copy / 单测为红；最终状态全绿。
- 卡 B 为续练计数改了 `home/today.js`、卡 C 为共用撤销计时改了 `result/index.js`，均超出原归属但理由成立，无冲突。
