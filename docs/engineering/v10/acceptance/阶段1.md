## 3. 合入中发现并处理（验收侧）

- **测试假通过**：P1-E7 的月字帖测试用整体替换造数据，带 `source` 的记录在 E7 分支上被 schema 拒绝、造数静默失败，测试「碰巧」通过；P1-E8 合入后造数生效、墨迹被清，测试变红。根因在测试造数，已修（P1-E78）；这条断言此后才真正验证「纸上字不进月字帖」。
- **随机失败**：70-p1e4-mix 对整组断言「不是保留字」，首练字「拾」可作提前复习补位出现（取决于 FSRS fuzz），改为只查新字。
- **合并误报**：字表数据「字频#3919」被颜色规则当成十六进制色，登记例外。
- **合并冲突**：copy-source.json 用三方 JSON 合并（两侧新增槽都保留、格式不变）；分享弹层、年报、练习记录以 P1-E7 新实现为准；verify_tokens 例外表以 P1-E1b 字墙参数为准。
- **补完被中断的卡**：P1-E7 停在「页头标题隐藏」一半（`:has()` 改 `hideTitle`），由验收者补完（iOS 15.4 以前不支持 `:has()`）。
- **书写格校准**：阶段 0 遗留的预留高度，P1-E1b 按页边 20 重算，iPhone 17 = 362pt，与设计稿一致。
