## 共识

1. **帮助层画法**（V3-01 S1、T3-02 S1）：去掉 ink3 外廓，改不透明淡朱实填（V 已核算浅/深对笺与对本人墨均 ≥3:1）；描一遍「当前一笔实心、其余双钩」。（这一外廓是第二轮 W1 验收时主控要求「与描一遍同画法」、代理为过对比度加的，判断失误，本轮改回。）
2. **WebKit 下 AX 缺陷**（A3-01 S1、A3-02）：SE3 AX3/AX5 书写格非正方形导致笔迹纵向压缩；`word-break:keep-all` 让中文整句不折行。已在修（卡 K1），并加 WebKit 门禁。
3. **主角屏构图**（T3-01 S1、T3-03/04、V3-02/09）：首页字帖满版心、主按钮回到全 App 统一底线；书写格顶边在所有阶段固定；常规字号写字页也只留「写好了 + ⋯」。
4. **「拾」交接看不见**（N3-01 S1、I3-06、T3-07）：先停 600ms，「退灰 → 写墨」，不交叉淡化两层；格下与结果页各一句「你写下的第一个「拾」。」
5. **落印三感不同步**（I3-04/05、T3-08）：rigid 触觉与 s1 在着纸那一帧同发；冷启动恢复不重演；结果页先只有作品，印落后再出文字与底栏。
6. **原生书写面 spike**（I3-13 S1）：连续两轮零进展，已开工（spike 卡）。
7. **作品与出口**：分享预览加纸边（V3-03、T3-06、N3-04）；「看后写的」进格内、落款永远最后一行（T、V3-08）；详情一个字只出现在头图与多出的记录里（V3-04、T3-11、N3-09）。
