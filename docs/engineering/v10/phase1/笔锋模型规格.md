# 笔锋模型规格（ink-model-1.0）

> 任务 P1-S1（阶段 1）。阶段 2 原生书写面（UIKit 触摸 + Metal，decisions.md D26 / D32）的实现契约。
> 解决审查 G01（墨是等宽记号笔）、为 G11（原生书写面）、G15（细节被核数门控）给出渲染侧规格。
> 输入：[I-交互动效](../ada-review/I-交互动效.md) I01、I03、§3-A；[V-视觉工艺](../ada-review/V-视觉工艺.md) V01；[汇总](../ada-review/汇总-ADA差距与路线.md) G01、G11、G15、T1、T2；决定 D09、D10、D26、D32、D33、D36。
> 配套：[ink-model/](ink-model/)（`vectors.json` 金标准向量、`reference.mjs` 参考实现、`check.mjs` 断言、`render-svg.mjs` 渲染、`out/` 渲染图）。
> 本规格只规定「原始点 → 渲染」的纯函数。**不改存储**：原始点仍是 InkV2 语义（x, y, t, p；v3 只是打包）。不改任何产品代码；`src/core/ink-math.js` 在网页阶段照旧运行。

## 0. 一段话

一笔墨 = **中线 + 宽度剖面**。中线来自原始点：零时间差合并 → 低滞后向量 1€ 滤波 → 向心 Catmull-Rom → **等弧长重采样**（Δs = 1 单位，故与 60/120/240Hz 无关）。宽度 = 本体宽 B × 本体因子（手指用速度，Pencil 用压力**替代**速度，D10）× **方向因子**（连续函数，笔锋「薄边」朝右上 25°：横 0.72、竖 1.12、↘ 最粗 1.2、↗ 提最细 0.5）× **阶段因子**（起笔顿 1.12→1.35→1、慢收顿圆 1.2、快收出锋到 0.12、钩锋到 0.10、点画 0.7→1.1→0.9 按 D09）。几何是「中线两侧偏移的三角带 + 斜切起笔 + 圆端帽 + 折肩斜接『耳』+ 钩的圆顿」的**并集**（非零规则，自交天然无洞），Metal 上一次画进单笔覆盖率纹理（MAX 混合）再上墨色与纸纹。全 App 只有这一个渲染器：书写格、对照卡、缩略图、字墙、分享图都用它，几何按 S/345 缩放，宽度只在小于 258pt 时按 (S/258)^−0.3 统一加粗（封顶 1.5），取消 ×1.41 特例。书写中距笔尖 ≥ 56 单位的部分一经算出永不再变（前缀稳定），每帧只重画尾段；抬笔不再一帧跳变。

## 1. 坐标、单位、采样率

| 量 | 单位 / 约定 |
|---|---|
| 位置 x, y | 书写格内部 **345 × 345 单位**（`GRID`，与显示尺寸无关），原点左上，**y 向下**。原生端：`touch.preciseLocation(in: gridView)`（pt）× 345 / S |
| 书写格显示尺寸 S | pt，按可用空间夹在 **[258, 400]**（D36）；1 单位 = S/345 pt |
| 设备像素 | 1 单位 = S/345 × `UIScreen.scale`（2 或 3）px。400pt@3x 时 1 单位 ≈ 3.5px；258pt@2x 时 ≈ 1.5px |
| 时间 t | **ms**，双精度，任意起点（只用差值）。原生端 `UITouch.timestamp × 1000`，**不得**取主线程收到事件的时刻 |
| 压力 p | [0, 1]，`force / maximumPossibleForce`，**仅 Pencil**。手指一律不写 p（即便 `force > 0`），保证手指笔迹在各机型一致 |
| 倾角 alt | 度，`altitudeAngle`（90 = 垂直）。**存储里没有**，见 §3.5 |
| 宽度 w | 345 单位，绝对笔宽（全宽，不是半宽） |
| 方向 θ | 弧度，y 向下坐标系：0 = 向右，+90° = 向下，−45° = 右上 |

**采样率无关性**（60Hz 手指旧机 / 120Hz ProMotion / 240Hz Pencil 合并点须得到视觉一致的墨）由四条规则共同保证，`check.mjs` 用同一笔的 60/120/240Hz 三份采样（V15–V17）和撇的 60/120Hz（V05/V18）断言：

1. **等弧长参数化**：所有宽度、方向、阶段计算都在等弧长样本上做（Δs = 1 单位），不在原始点上做。
2. **段内时间按弧长线性**：重采样时每个原始段内 t（与 p）按弧长线性插值，于是速度 = 段弧长 / 段时长，匀速笔在任何采样率下得到相同速度。
3. **所有平滑用连续时间常数**：α = 1 − e^(−Δt/τ)（宽度平滑、1€ 滤波都用指数形式），不用「每样本 α」。
4. **方向窗按弧长**：θ 取 [s − 6, s + 6] 两点连线；窗长必须 ≥ 60Hz 快写时相邻原始点距离的一半，否则位置抖动直接变成宽度纹波（实测 ±2.5 窗时纹波 ±5%）。

断言口径：u = 0.05…0.95 逐位置 |Δw| ≤ max(5%·w, 0.04·B)，面积差 ≤ 3%，端帽一致，弧长差 ≤ 1%。

## 2. 输入预处理

### 2.1 原生层接口约定（判定在原生层，本模型只消费结果）

| 事件 | 内容 | 本模型的处理 |
|---|---|---|
| `begin` | 第一个原始点 | 新笔开始 |
| `move` | **合并点**（`coalescedTouches(for:)`，全部按时间顺序当原始点）+ **预测点**（`predictedTouches(for:)`） | 合并点追加进本笔原始点；预测点**只用于这一帧显示**（§7.3），不进原始点、不进滤波器状态，下一帧丢弃 |
| `end` | 最后一个原始点 | `final = true` 重算尾段（§7.2），抬笔补间 70ms（§7.4）；原始点按现有 `encodeRawStrokes` 格式交给 JS 侧判断/存储 |
| `cancel` | — | 丢弃整笔（与现行 `ink-canvas.js` 一致：不固化、不计笔数） |

- **掌托 / 多指**：原生层决定哪一个 touch 是「写字的那一个」（I15 建议：接触面积小 + 移动像书写；面积大且 120ms 内静止判为手掌；有 Pencil 时忽略手指）。本模型只接受一路 touch 流；被判为掌托的 touch 不得进入 `move`。判定被推翻时（先认的 touch 后被判为手掌）发 `cancel`。
- **抖动**：不在原生层做空间去抖；原地抖动由 §2.3 滤波 + §2.4 重采样 + 方向窗吸收。原生层只需保证时间戳单调（不单调的点夹到前一点时间，再按零时间差合并）。
- **悬停**（D32）：`UIHoverGestureRecognizer` 的位置只用于显示一个落笔预览点（直径 = 0.9 × B × F_p(0.35)），不进本模型、不存。双击不涉及墨。

### 2.2 合并与清洗（`prepare`）

- 坏点（x 或 y 非有限）丢弃；t 非有限取前一点 t。
- **零时间差合并（D09）**：t 与前一点相等时覆盖前一点（留最后的位置），不参与速度计算。断言 I1：含重复点的 V01 与去重后输入逐样本相同。
- p 夹到 [0, 1]；p ≤ 0 视为无压力。

### 2.3 位置滤波：向量 1€（指数 α），滞后上限

替代现行 1€（minCutoff 1Hz、β 0.02、dCutoff 1Hz，实测滞后 2.3–6.6 单位，I03）：

```
dt  = (t − t_prev)/1000                      // s
sp  = |x − x̂_prev| / dt                      // 两轴合成速度，单位/s
d̂   = lerp(d̂_prev, sp, 1 − e^(−2π·fd·dt))    // fd = euroDCutoff = 10Hz
fc  = euroMinCutoff + euroBeta · d̂           // 6Hz + 0.15 · d̂
x̂   = lerp(x̂_prev, x, 1 − e^(−2π·fc·dt))    // x、y 共用 fc
```

- 抬笔时末点锁到原始末点（沿现行做法），只影响最后两段。
- **滞后上限**：匀速直线稳态下位置滞后 ≤ **max(0.75 单位, v × 8.33ms)**，即 120Hz 下 ≤ 1 帧；慢于 0.09 单位/ms 时 ≤ 0.75 单位（258pt 格 ≈ 0.56pt）。断言 I5。默认参数实测：

| v（单位/ms） | 0.05 | 0.1 | 0.3 | 0.6 | 1.2 |
|---|---|---|---|---|---|
| 新参数 120Hz 滞后（单位） | 0.26 | 0.28 | 0.16 | 0.03 | 0.00 |
| 新参数 240Hz | 0.26 | 0.31 | 0.31 | 0.18 | 0.04 |
| 现行参数 120Hz | 2.33 | 3.58 | 5.17 | 5.50 | 5.46 |

快写时几乎不滤（抖动相对笔画尺度不可见），慢写时 6Hz 低通吸收手指微颤；宽度上的抖动由方向窗与 τ 平滑负责。

### 2.4 中线重采样

1. 向心 Catmull-Rom（α = 0.5，Barry–Goldman 求值）过滤后的点；首尾用镜像点补控制点（不重复端点，避免零长结点）。向心形式在钩、折这种急转处不打圈、不过冲。
2. 每段稠密化到 ≤ 0.25 单位一点；段内 t、p 按**弧长**线性插值（§1 规则 2）。零长段（停顿）的全部时间计入停顿点之后下一个样本的 Δt。
3. 按累计弧长等距取样 s_k = k·Δs（Δs = 1），末样本恰在 s = len。

样本速度 v_k = (s_k − s_{k−1}) / (t_k − t_{k−1})（Δt = 0 时沿用上一值），v_0 = v_1。

## 3. 宽度模型

### 3.1 总式

```
w(s) = clamp( B · F̃_body(s) · F_dir(θ(s)) · F_phase(s),  0.04B, 2.4B )
F̃_body：本体因子按时间平滑   F̃_k = F̃_{k−1} + (target_k − F̃_{k−1})·(1 − e^(−Δt/τ)),  τ = 35ms，F̃_0 = target_0
target = (有压力 ? F_p(p) : F_v(v)) · F_tilt(alt)          ← D10：压力替代速度，不叠乘
「本体宽」 = B · F̃_body · F_dir                             ← D09 的点画倍数、单点 0.9 都乘在它上面
```

左右半宽 hwL = hwR = w/2（契约里分开记，1.x 留给倾角方位角做侧锋不对称）。

### 3.2 本体宽 B

B = **13**（345 单位；I §3-A 建议从 11.5 提到 13）。方向因子平均约 0.9、速度因子常速约 0.85，整体墨量与现行 11.5 等宽相当：慢横 ≈ 8 单位、慢竖 ≈ 13 单位。

### 3.3 速度因子 F_v（手指）

```
F_v(v) = 1 − (1 − vMin)·(1 − e^(−min(v, 1.5)/vK)),   vMin = 0.62, vK = 0.55 单位/ms
```

| v | 0 | 0.1 | 0.2 | 0.3 | 0.6 | 0.9 | 1.2 | 1.5 |
|---|---|---|---|---|---|---|---|---|
| F_v | 1.000 | 0.937 | 0.884 | 0.840 | 0.748 | 0.694 | 0.663 | 0.645 |

单调、连续、静止为 1（故单点 = 0.9B 与现行一致）。范围 1 : 0.645（现行 1.06 : 0.88）；speedCap 1.5 沿交接备注八.1。

### 3.4 压力因子 F_p（Pencil，D10）

```
F_p(p) = clamp(pLo + √p · pGain, pLo, pHi),   pLo = 0.42, pGain = 0.92, pHi = 1.38
```

- **替代** F_v，不叠乘（D10）；方向因子与阶段因子照乘（与现行「起笔 / 收笔 / 点画倍数照乘」同一原则）。断言 I2：同一压力曲线、速度 ×2（V13/V14），中段宽差 ≤ 4%，中段 F̃_body ≈ F_p(p)。
- 默认值从 policy.ink 过渡值（.58 / .94 / 1.52）下调：旧值是在没有方向因子时定的，叠上竖 1.12 后 Pencil 竖画达 1.45B，明显比手指粗。新值让常见书写力 p ≈ 0.35 时 F_p ≈ 0.96（≈ 手指慢写）。这是 P65 待真机值的调整，**不是**对 D10 的覆盖。
- `dirPencil`（默认 1）：有压力时方向因子的强度 F = 1 + (F_dir − 1)·dirPencil。留给 T2 判断「Pencil 下是否仍要横细竖粗」。

### 3.5 倾角因子 F_tilt（Pencil 侧锋）

```
F_tilt(alt) = 1 + tiltGain · clamp((60° − alt)/60°, 0, 1)
```

笔越平越宽（侧锋）。**默认 tiltGain = 0（关）**：InkV2 原始点没有倾角，若书写时用倾角而回放 / 缩略图拿不到，同一笔会「写时粗、回看细」，违反 §6 的一致性。启用（建议 0.3）的前提是原始点格式增加可选 alt 字段，属于存储变更，需另行决定（§9.3）。方位角（azimuth）1.0 不用，保留给侧锋不对称（hwL ≠ hwR）。

### 3.6 方向因子 F_dir（连续函数）

把硬笔楷书「横细竖粗、↘ 最重、↗ 最轻」统一成一支「薄边」朝右上 25° 的笔：

```
F_dir(θ) = max(dirMin, a + b·|sin(θ − dirAngle)|),  dirAngle = −25°, dirMin = 0.5
a、b 由两个锚点解出：F_dir(0°) = dirH = 0.72（横）、F_dir(90°) = dirV = 1.12（竖）→ a = 0.371, b = 0.827
θ(s) = 方向(P(s − 6) → P(s + 6))，按弧长取窗（§1 规则 4）
```

| 方向 | 提 ↗ −45° | 「薄边」−25° | 横 0° | 捺 30° | ↘ 45° | 最粗 65° | 竖 90° | 撇 120° | 撇 135° |
|---|---|---|---|---|---|---|---|---|---|
| F_dir | 0.653 | 0.500 | **0.720** | 1.048 | 1.148 | 1.197 | **1.120** | 0.845 | 0.653 |

- 与 I §3-A「横 0.72、竖 1.12，按 |cos| 插值」的区别：|cos| 插值分不出 ↘ 与 ↗（点、捺 与 提、撇 一样粗），这里用一个角度参数就同时得到「捺重撇轻、点重提轻」，且只有 3 个可调量（dirAngle、dirH、dirV）。
- 撇越写越细（V05：w(0.7)/w(0.2) ≈ 0.50）同时来自加速和方向转向「薄边」。
- 方向因子是几何量，不按时间平滑（转角处的过渡宽度 ≈ 2 × 6 单位）。

### 3.7 阶段因子 F_phase

**起笔**（非点画）：

```
v_in = 落笔后 40ms 均速（liftSpeed 的镜像，不足 40ms 用整段时长）
k_in = clamp((v_in − lo)/(hi − lo), 0, 1)
Le   = clamp(v_in · 40ms, 5, 12) 单位
peak = 1 + (entryPeak − 1)·(1 − 0.4·k_in)          // 慢起 1.35，快起 1.21
F_entry(s) = s < 0.35Le : lerp(1.12, peak, smooth(s/0.35Le))
             s < Le     : lerp(peak, 1, smooth((s − 0.35Le)/0.65Le))
             否则 1
```

起笔的「斜切」是几何（§4.3），不在宽度里。

**收笔**（非点画、非钩；与 D09 / 交接备注八.1 同口径看抬笔前 30ms 均速 v30，不足 30ms 用整段时长）：

```
kk     = clamp((v30 − lo)/(hi − lo), 0, 1),  lo = 0.25, hi = 0.9 单位/ms
慢收顿 F_slow(s) = 1 + (stopPeak − 1)·smooth(1 − d/Ls),  d = len − s < Ls = 7；stopPeak = 1.2
快出锋 F_fast(s) = endFast + (1 − endFast)·(d/Lt)^0.6,   d < Lt；endFast = 0.12
       Lt = min(0.4·len, lerp(20, 34, kk))               // 25–35pt 出锋（I §3-A），短笔按比例缩
F_exit = lerp(F_slow, F_fast, kk)                       // 中间线性过渡（I §3-A）
```

慢收另在几何上把末端圆向 ↘ 偏出 0.22·w_end·(1 − kk)（顿笔，§4.4）。端帽类型由剖面推出：末端宽 / 末端本体宽 ≥ 0.5 为 `round`，否则 `taper`。

**点画（D09）**：抬笔后总弧长 < dotLen = 24 时整笔改用点画倍数，**乘本体宽**：

```
u = s/len;  F_dot(u) = u < 0.5 ? lerp(0.7, 1.1, u/0.5) : lerp(1.1, 0.9, (u − 0.5)/0.5)
```

不叠加起笔顿、收笔、钩。点画的入笔方向通常接近 45°（↘），与斜切线近平行，几何上自动成尖头 → 水滴形「点」（V08）。断言：w = 本体宽 × F_dot 逐样本精确成立。

**单点（D09）**：合并后只有一个点或总位移为 0 → 圆盘，直径 = **0.9 × 本体宽** = 0.9 × B × (有压力 ? F_p(p) : 1) × F_tilt。方向无定义，取 1。断言 V09：直径 / B = 0.900，面积 = π(0.45B)²。

### 3.8 折

- 检测：等弧长样本上 turn(s) = 方向(P(s)→P(s+6)) − 方向(P(s−6)→P(s))；|turn| ≥ cornerAngle = 65° 的连续段取局部最大为一个折角（距两端 < 3 单位不算）。
- 宽度不额外加：折角前后横细竖粗、转角处慢下来（F_v 变大）和停顿洇墨已经给出「顿」。
- 几何上在外侧加「肩」（§4.4）。

### 3.9 钩

判定（全部满足）：

1. 最后一个折角 |turn| ≥ **hookAngle = 100°**；
2. 折角之后的弧长 ∈ [4, 45] 单位（钩是笔画末段且短）；
3. 离开折角后 60ms 内的速度峰值 ≥ **1.6 ×** 折角前均速（= s_c / (t_c − t_0)，不含转角处停顿）。

生成：折角后 2 单位起整段按钩锋收尖 F_hook = 0.10 + 0.90·u^0.7（u = 剩余弧长 / 钩段长），不再叠加普通收笔；转角处加圆顿（§4.4）。

条件 3 不满足时（V12：转角够大但慢慢挑出）**不替用户补钩**，如实画成一个慢折、慢收顿圆。这是「只判写没写对、不评美观」原则（D01/D03 精神）在墨上的延伸：模型强化用户真实的动作，不发明动作。

### 3.10 时间平滑与夹值

- τ = 35ms 只平滑本体因子（速度 / 压力），沿交接备注八.1。
- 宽度夹在 [0.04B, 2.4B]：上限防止 Pencil 压到底 + ↘ + 起笔顿叠出墨团；下限保证出锋尖端在 400pt@3x 下仍 ≥ 1.8px（再细由 §6.3 发丝线规则接管）。

### 3.11 参数表

「T2」= 必须真机由 2–3 位能写规范硬笔楷书的人盲测调定（汇总 T2：原生 spike 上 2–3 套笔模型各写 20 字，再请 8–10 位 40–65 岁用户盲选），定稿写入 `policy.ink`（P65）。其余为结构性参数，改动需同步重新生成向量。

| 参数 | 默认 | 范围 | 对视觉的作用 | T2 |
|---|---|---|---|---|
| `base` B | 13 | 10–16 | 整体墨量 / 笔的粗细档 | **是** |
| `vMin` | 0.62 | 0.5–0.85 | 快写最细到本体的多少；越小提按越明显 | **是** |
| `vK` | 0.55 单位/ms | 0.3–1.0 | 速度变细的「快慢」拐点 | **是** |
| `speedCap` | 1.5 | 已定（八.1） | 速度上限 | — |
| `tau` | 35ms | 已定（八.1） | 宽度跟随速度的迟滞；越大越稳越钝 | — |

## 4. 几何输出

### 4.1 方案比较：变宽轮廓（三角带）vs 逐段印章（stamp），在 Metal 上

| | **A 变宽轮廓：中线两侧偏移成三角带** | B 印章：沿弧长每 ≤ 0.25w 盖一个圆 / 椭圆 |
|---|---|---|
| 边缘 | 直边、斜切、尖角、折肩都精确可控 | 天生圆润；斜切起笔、折肩「耳」很难做硬 |
| 顶点量（230 单位竖） | ≈ 460 三角形 / 笔 | ≈ 500–900 实例四边形 / 笔，片元重叠 3–5 倍 |
| 重叠 | 三角带在急转内侧会折叠 → 需「并集」语义 | 必然大量重叠 → 也需 MAX 混合 |
| 抗锯齿 | 两侧长边可做解析 AA（顶点带横向坐标 n）；端帽 / 楔用 4×MSAA | 每个印章 SDF，边缘呈细微扇贝纹（间距与宽度比敏感） |
| 纹理（飞白沿笔向） | 片元天然有 (s, n) 笔画坐标，条纹沿 s 拉长即可 | 印章贴图沿笔重复，有周期感（现行虚线飞白的老问题） |
| 增量 | 只追加尾段三角形 | 只追加尾段印章 |
| 可测试性 | 几何是确定的多边形集合：面积、端帽、外包可断言，原生与 JS 同口径 | 只能断言像素 |
| 矢量导出（分享图 / 年报 PDF） | 同一组多边形直接交给 CoreGraphics / PDF | 需另行求轮廓 |

**选 A。** 楷书硬笔的辨识度来自斜切起笔、折肩、悬针与钩的尖——都是「硬边」，印章做不硬；而 A 的几何可以被断言，正是「原生与 JS 参考共用同一份向量」的前提。

### 4.2 三角带与并集

- 样本 i 的切向 T_i = 归一化(P_{i+1} − P_{i−1})（端点单侧），法向 N_i = (−T.y, T.x)（y 向下坐标中为行笔方向的视觉右侧）。
- L_i = P_i + N_i·hwL_i，R_i = P_i − N_i·hwR_i；每对相邻样本出两个三角形 (L_i, R_i, R_{i+1})、(L_i, R_{i+1}, L_{i+1})。
- **语义是所有片的并集**：每个多边形统一为逆时针，按非零规则填充 = 并集。急转内侧的折叠、钩与竖的重叠都不会出洞，也不会叠深。
  - Metal：一笔的全部三角形画进单笔覆盖率纹理（R8，混合 `max`，不剔除背面），再合成到画布。
  - CoreGraphics / PDF：全部多边形放进同一个 path，`fillPath(using: .winding)`。
- 面积断言用同一个并集（扫描线，行距 0.1 单位，非零规则）。

### 4.3 起笔斜切

右手执笔落笔时向右下（↘）一顿：斜切线过起点 P0、方向 cutAngle = 45°。

1. 起笔方向 θ0 = 方向(P0 → P(6))（「前 6 单位方向」）。
2. rel = 斜切线与行笔方向的锐角夹角。rel < cutMinRel（30°）时把斜切线转到恰好 30°（朝原来一侧）。
3. 在起点后方沿 −θ0 延伸 e = hw0 / tan(max(rel, 30°)) + 0.5，补一个同宽四边形。
4. 把延伸块与 s ≤ 2e + 2 的三角形用斜切线裁剪，保留行笔一侧。

结果：横（rel = 45°）是左上角探出、左下角切掉的平行四边形头；竖（rel = 45°）是顶边左高右低的斜面；撇、提（rel 65°–80°）接近平头微斜；点、捺（入笔方向近 45°，rel < 35°）自动成**尖起笔**。端帽类型：rel < 35° 记 `point`，否则 `cut`。

### 4.4 末端、折肩、钩顿

- **末端**：半圆扇（16 段），半径 = 末样本半宽。出锋时半宽 ≤ 0.06B，即尖。
- **慢收顿**（端帽 `round` 且 kk < 1）：再并一个圆，圆心 = 末点 + ↘·0.22·w_end·(1 − kk)，半径 0.92·w_end/2。
- **折肩「耳」**（非钩的折角）：进段外侧边线（用折角前 6 单位处的半宽）与出段外侧边线（折角后 6 单位处的半宽）求交得斜接点 M，再沿外角平分线推出 cornerBoost × 出段半宽，距中心不超过 miterLimit × 较大半宽；并入四边形 (P_c, A_in, M, C_out)。不能用折角处（更宽的）半宽画进段边线——那会在横画上方立起一个方块（已在渲染图里排除）。
- **钩的转角圆顿**：并一个圆，半径 = w_c/2 × (1 + hookPress/2)，圆心向 ↘ 偏出 0.12·w_c；不用斜接（钩底是按下去的圆，不是尖角）。

### 4.5 自交

不求轮廓布尔运算，也不去除内侧折叠：并集语义（§4.2）让所有自交在渲染和面积上都正确。代价是几何里有冗余三角形（230 单位竖 ≈ 460 个），对 GPU 无关紧要。

## 5. 质感

### 5.1 墨色与纸（两套）

| | 纸（书写格底 `--c`） | 墨（`--i1`） | 纸纹调制 | 飞白露出 |
|---|---|---|---|---|
| 浅色纸 | `#FBF8F2` | `#3B2F28` | 墨的明度起伏 3–5%（I §3-A；SVG 近似 grain 0.07），边缘位移 ≤ ±0.35 单位 | 纸色 |
| 夜间纸 | `#2D2823` | `#DCCFB8` | 起伏略强 4–6%（浅墨在深纸上起伏不易察觉；SVG 近似 grain 0.09），边缘同上 | 纸色 |

取 `src/config/tokens.css` 现值；D33「深色做独立的夜间纸」重建后跟随新 token，模型只引用 token 名。夜间纸的墨不是反相：几何、飞白位置、洇墨位置与浅色完全相同，只换颜色和纸纹强度。

### 5.2 飞白（快笔）

- 干度 dry(s) = feibaiMax · smoothstep((v̄(s) − 0.7)/(1.4 − 0.7))，v̄ 为按 τ 平滑的速度。
- 表现：沿笔向（s 方向）拉长、横向（n 方向）很窄的断续细缝，露出纸色；条纹由确定性噪声 noise(s/7.5, 车道, 本笔种子) < 1.1·dry 决定，车道约 6 条分布在 |n| ≤ 0.66，缝宽 ≈ 0.045w·(0.6 + dry)、不透明度 0.6。硬笔飞白要轻：最重时露白约为笔面积的 5–8%（按缝宽 × 车道 × 占空比估算），不做成毛笔式的大片枯笔。
- **确定性**：种子 = 本笔前 8 个原始点的哈希。同一笔在书写格、缩略图、分享图里飞白位置一模一样。
- 夜间纸同样露纸色。

### 5.3 洇墨（停顿）与纸纹

- 停顿：原始点在半径 1.2 单位内停留 ≥ 60ms → 一处洇墨，强度 = min(1, 停留 / 300ms)，位置取停留点的平均。慢收（kk < 0.2）在末端再加一处，强度 0.35·(1 − kk/0.2)。
- 表现：在本笔下方画墨色晕圈，半径 = 本处半宽 + 0.6 + 1.3·强度（单位），不透明度 0.14·(0.5 + 强度) 径向衰减到 0。
- 纸纹：一张固定的平铺噪声（各向异性，横向频率约为纵向 4 倍，像纸的纤维），锚定在 **345 单位空间**（随字缩放，故同一个字各处一样；小尺寸时自然平均掉）。用于墨的不透明度调制和边缘位移；纸面本身的纹理是另一层，按 pt 锚定，不属于本模型。

### 5.4 湿墨变干（只用于显示）

抬笔后 200ms 内：不透明度 0.9 → 1，边缘由 −0.4 单位外扩到 0（墨吃进纸）。**最终态 = 规范几何**，所以静态渲染（缩略图、分享图）就是干墨，无需动画状态。

### 5.5 减少动态效果（D10）

开启「减少动态效果」时：飞白、洇墨关闭（沿现行），湿墨变干与抬笔补间也关闭（直接终态）。**形状不变**：宽度剖面、端帽、钩、折肩完全相同（断言 I7）。笔锋是墨的形状，不是动效。

### 5.6 不按 CPU 核数门控（G15）

细节只受「减少动态效果」一个开关控制，不读 `hardwareConcurrency` / `deviceMemory`（WebKit 会钳低，现行门控可能在所有 iPhone 上关掉细节）。原生端在 GPU 预算超支时（热降频）按顺序降级：先关纸纹边缘位移 → 再关飞白 → 永不降级形状。

## 6. 一致性：全 App 一个渲染器

### 6.1 同一个函数

书写格、判断页对照卡、结果页格子、字墙、单字详情、字帖、分享图、年报全部调用同一个 `render(rawStrokes, S, theme)`：同一套参数、同一个 modelVersion、同一个飞白种子。不再有「对照卡 ×1.41」「缩略图另一套线宽」之类特例（R11 / N14：同一个人的字在三处是三种粗细）。

### 6.2 宽度如何随显示尺寸变

```
几何坐标  × S/345
线宽      × S/345 × sizeComp(S)
sizeComp(S) = 1                               S ≥ 258（书写格全范围 D36）
            = min(1.5, (S/258)^−0.3)          S < 258
```

| S（pt） | 400 / 345 / 258 | 166.5（对照卡） | 120 | 96 | ≤ 64（字墙） |
|---|---|---|---|---|---|
| sizeComp | 1.00 | 1.14（取代 ×1.41） | 1.26 | 1.35 | 1.50 |

- 书写格 258–400 纯几何缩放：在 SE 和 Pro Max 上写出的字是同一张图的放大缩小。
- 小尺寸时笔画的绝对宽度掉到 1–2px，感知上会变「轻、虚」，所以像字体的光学尺寸一样**整体**加粗：所有样本宽度乘同一个数，粗细比、出锋形状、起笔斜切全部保留——这正是「同一个人的字」的辨识特征。×1.41 的问题是它只为一个尺寸拍出来、而且过重（等效 0.68 倍线性缩放），三处观感不一。
- 渲染图 `out/sheet-chars-*.png` 第二行是同一个「永」在 400 / 258 / 166.5 / 96 / 64pt 的效果。

### 6.3 发丝线

任一处宽度换算到设备像素 < 0.75px 时，按 0.75px 画、覆盖率乘 w/0.75（保持墨量），避免出锋尖端在小图上断续闪烁。这一条只在原生光栅化里做；参考实现的几何不含它（SVG 由浏览器抗锯齿），面积断言也不含它。

### 6.4 存储形态与回放

- 原始点（`encodeRawStrokes` 格式，书写现场与 D27 之后的全量留存）→ 走本规格全管线，与书写时逐样本一致（纯函数 + 前缀稳定）。
- 已压缩的 Ink v3（每笔 ≤ 24 点、dt 量化、w 已烘焙为旧模型宽度）不是原始点，只能「近似回放」：解码点（x, y, w）→ §2.4 重采样（w 线性）→ §4 几何（斜切、圆端帽照常；折角按几何重新检测；钩按「末段转角 ≥ 100° 且末端宽 / 转角宽 < 0.3」判定）。旧数据里烘焙的是现行等宽墨的 w，回放出来仍像旧墨（D15：目前无正式用户，可接受）。
- 建议（不在本任务范围）：D27 的「最近一次 + 第一次」留存若仍用 v3，抽点改为保留曲率极值点（格式不变），否则 24 点均匀抽样会削掉钩与折肩；阶段 2 原生 SQLite 后改存原始点（DQ2-C）。

## 7. 性能与实时

### 7.1 预算（iPhone 17 / 120Hz；SE3 按 60Hz 同口径，1 帧 = 16.7ms）

| 环节 | 预算 |
|---|---|
| 触点到墨迹（motion-to-photon） | 与备忘录手写差 **≤ 1 帧**（120Hz 约 8.3ms），T1 用 240fps 慢动作测 |
| 每帧 CPU（新原始点处理 + 尾段重算 + 尾段几何） | ≤ 1.0ms（尾段 ≤ 60 样本、≤ 130 三角形） |
| 每帧 GPU（400pt@3x 书写格） | ≤ 2.0ms |
| 缩略图（字墙 64pt@3x，每字） | CPU 分析 ≤ 0.3ms/笔（参考实现 node 全量 0.27ms/笔），GPU ≤ 0.5ms/字；结果按 (原始点哈希, 像素尺寸, 主题, modelVersion) 缓存 |

原生实现要点（阶段 2 spike P1-S2 验证）：`CADisplayLink.preferredFrameRateRange` 120 与 Info.plist `CADisableMinimumFrameDurationOnPhone = YES`；CAMetalLayer 直接呈现，不经过 WKWebView；墨迹路径上不调 JavaScriptCore（领域逻辑只在抬笔后拿原始点）；触觉在同一帧发出。

### 7.2 增量渲染与前缀稳定

- 三层：已完成笔画纹理（只在撤销 / 清空 / 换字 / 尺寸或主题变化时重画）→ 当前笔的**冻结前缀**（只追加）→ 当前笔的**临时尾段**（每帧重画，含预测段）。
- **冻结线**：距笔尖弧长 Z = max(56, 最后两个原始段弧长 + 6) 单位之前的样本，此后任何新点、抬笔都不再改变它们（宽度与位置差 ≤ 1e-6）。理由：所有依赖都有界——1€ 与宽度平滑是因果的；Catmull-Rom 只看前后各 1–2 点；方向窗 ±6；收笔区 ≤ 34；钩段 ≤ 45 + 圆顿；点画只在总长 < 24 时生效。断言 I4 对 6 条向量在 40% / 60% / 80% / 95% 处截断检查（落笔后 40ms 内起笔参数 v_in 未定，整笔都算临时）。
- 每帧只把「上一冻结线 → 新冻结线」之间的三角形追加进当前笔覆盖率纹理，再重画临时尾段。

### 7.3 预测点

`predictedTouches` 追加在滤波后中线末端（不经滤波器，不改其状态），宽度 × 0.9，只画在临时尾段；下一帧被真实点替换，抬笔即丢弃。外推最多 16ms。

### 7.4 抬笔不跳变

- 书写中尾端按「此刻抬笔」的收笔形态**预混** liftBlend = 0.5：F_exit_live = lerp(1, F_exit, 0.5)。快写时尾巴已经半尖，减速时已经半圆。
- 抬笔时临时尾段从预混态 ease-out 补到终态（70ms），之后整笔固化。终态与 `final = true` 的纯函数结果严格相同。
- 减少动态效果时不补间，直接终态。

## 8. 金标准测试向量

### 8.1 文件与口径

`ink-model/vectors.json`：20 条向量 + 4 个演示字（永、大、十、心，只供人看）。每条：`points`（原始点 JSON：x, y, t, p?）+ `expect`（可断言特征）。输入由 `gen-vectors.mjs` 合成（中线 + 速度关键帧 + 停顿 + 采样率 + 高斯抖动 0.05–0.15 单位 + 时间抖动 ±0.15ms，固定种子）。**期望值不调用参考实现**：中心值用本规格的闭式公式（F_v、F_dir、F_p、阶段因子）按合成时的名义速度 / 方向算出，再给容差；结构性断言按条文写。

| ID | 内容 | 采样 | 主要断言 |
|---|---|---|---|
| V01 | 慢横（含 3 个零时间差重复点） | 120Hz 手指 | 横细 w/B≈0.61；cut / round；慢收顿 endRel 0.95–1.35；有洇墨；无飞白 |
| V02 | 快横 | 120Hz | 中段 ≈0.48；taper，尖端 ≤ 0.12B；有飞白 |

### 8.2 两层断言

- **结构层**：任何落在 §3.11 取值范围内的参数都必须成立（例如：慢挑不出钩、点画倍数、单点 0.9、压力替代速度、采样率无关、前缀稳定）。
- **数值层**：绑定默认参数（`paramsVersion`）。T2 调参后按 §8.4 重新生成。

### 8.3 全局不变量（`check.mjs` 内）

| | 内容 |
|---|---|
| I1 | D09 零时间差合并：含重复点输入 ≡ 去重输入 |
| I2 | D10：速度 ×2 中段宽差 ≤ 4%；中段 F̃_body ≈ F_p(p) |
| I3 | 60Hz vs 240Hz 面积差 ≤ 3% |
| I4 | 前缀稳定：6 条向量 × 4 个截断点，冻结区宽度 / 位置差 ≤ 1e-6 |
| I5 | 1€ 滞后上限：v = 0.05–1.5，≤ max(0.75, v·8.33ms) |
| I6 | 平移 (+5.5, −3.25) 与时间原点 +123456.789ms 不变 |
| I7 | 减少动态效果：无飞白 / 洇墨，宽度与几何面积完全不变 |
| I8 | sizeComp：258–400 为 1；166.5 ≈ 1.14；≤ 64 封顶 1.5；单调 |
| I9 | 几何健全：多边形逆时针；并集面积 ≤ 分片面积和；轮廓在样本 ± 1.8w 包络内 |
| I10 | 同速慢竖 / 慢横中段宽比 ∈ [1.45, 1.75] |

**当前结果：20 条向量、314 条断言全部通过。** 另做了变异测试（只用于确认断言有牙齿，不入库）：去掉方向因子 → 33 条失败；压力与速度叠乘（违反 D10）→ 10；点画倍数改 1 → 4；钩判定不看速度 → 3；斜切角改 0 → 10；换回现行 1€ 参数 → 5；去掉出锋 → 17；单点改 1.0 → 2。

### 8.4 原生端怎么用；调参后怎么更新

- 原生端（XCTest）读同一份 `vectors.json`，对每条向量输出 profile（逐样本 s, w, fPhase, body）与几何多边形，按 §8.1 / §8.3 同一口径断言。浮点实现差异允许：数值层区间不变；前缀稳定的 1e-6 放宽到 1e-4。
- T2 定稿后：改 `reference.mjs` 的 `PARAMS` 与 `gen-vectors.mjs` 的 `SPEC` → `node gen-vectors.mjs` → `node check.mjs` → `node render-svg.mjs && node svg-to-png.mjs` → 人看渲染图 → 提交，并把 `paramsVersion` 加一。结构层断言失败说明参数越出了模型的有效范围，不是改向量能解决的。

## 9. 与 D09 / D10 的兼容，以及需要产品负责人另行覆盖的条目

### 9.1 D09（点画倍数乘本体宽；短于 30ms 用整段时长；单点 0.9 × 本体宽；零时间差合并）——**完全兼容**

| D09 条文 | 本规格 | 断言 |
|---|---|---|
| 点画倍数乘本体宽 | 0.7 → 1.1 → 0.9 × 本体宽，dotLen 24 不变。本体宽现在含方向因子（B·F̃_body·F_dir），这是「本体宽」定义的扩展，不改条文 | V08 dotPhase、w = body × phase |
| 短于 30ms 用整段时长 | `liftSpeed` 与现行逐行同算法（窗口插值到恰好 30ms，分子分母同段）；起笔 40ms 窗镜像同口径 | V19 v30WholeDuration |
| 单点直径 0.9 × 本体宽 | 0.9 × B × (F_p 或 1) | V09 |
| 零时间差点合并、不参与速度 | `prepare` 同语义 | I1 |

### 9.2 D10（压力替代速度不叠乘；飞白 / 洇墨 / 减少动态效果沿约定的现有处理）

- **前半句兼容**：压力替代速度本体因子、不叠乘（I2）。方向因子与阶段因子照乘，与现行「起笔 / 收笔 / 点画倍数照乘」同一原则。压力映射的默认值改了（.58/.94/1.52 → .42/.92/1.38），那是 P65「待真机」值，不是 D10 条文。
- **后半句需要覆盖**——请产品负责人在 decisions.md 记一条（建议 D37）：
  1. 飞白由「两样本间瞬时速度 > 1.05 时用虚线擦出规则缝」改为 §5.2（平滑速度 0.7–1.4 驱动、沿笔向的确定性干笔条纹）。现行的规则虚线正是 I01 指出的「机械纹理」。
  2. 洇墨由「两样本间 Δt > 52ms 处画 α .11 小晕」改为 §5.3（原始点停留 ≥ 60ms 且半径 ≤ 1.2，强度随停留时长；慢收末端加一处）。现行判据依赖采样率，违反 §1。
  3. 细节门控去掉「核数 > 2、内存 > 2GB」，只看「减少动态效果」（G15，汇总 A3 推荐）。
  4. 「减少动态效果」的处理保持不变（关飞白 / 洇墨），并明确扩展到湿墨变干与抬笔补间；形状不受影响。

### 9.3 交接备注八.1 的其余「已定规格」

代码里 `INK_SPEC` 五项全部保留（speedCap 1.5、τ 35ms、window 30ms、dotLen 24、single 0.9）。被本规格取代、同样需要在建议的 D37 里写明的：

| 八.1 / 现行 | 本规格 |
|---|---|
| 本体宽 = BASE × (1.06 − 0.12·min(v, 1.5))，BASE 11.5 | B 13 × F_v（§3.3），另乘方向因子 |
| 起笔 0.85× → 1.08× → 1.0×（前 6 / 12 单位） | 起笔顿 1.12 → 1.35 → 1（随起笔速度 5–12 单位）+ 几何斜切 |

| 1€（1Hz / 0.02 / 1Hz）+ 均匀 Catmull-Rom 每 3 单位 | 向量 1€（6Hz / 0.15 / 10Hz，指数 α）+ 向心 Catmull-Rom + 等弧长 1 单位 |

## 10. 不确定与风险

1. **方向因子是「风格化」而不是硬笔的物理事实。** 真实的中性笔 / 圆珠笔没有方向粗细；横细竖粗来自钢笔尖和书写习惯。本模型把它做成一支「薄边朝右上 25°」的笔，渲染图看来像规范硬笔楷书（`out/sheet-chars-*.png`），但对写得歪、写得快、左手书写的人是否仍自然，只有 T2 能回答。左手用户可能需要镜像的 dirAngle / cutAngle（未建模）。
2. **钩的速度判据会漏判慢而认真的初学者。** 1.6 倍峰速阈值让「慢慢挑出」不生成钩锋（V12）——这是有意的（不替用户补钩），但用户可能会觉得「我明明写了钩，为什么没有尖」。阈值与「慢挑是否至少给一个弱钩锋」需要 T2 盲测。
3. **抬笔前的尾端预混（liftBlend 0.5）与 70ms 补间是否被察觉为「墨在动」。** I03 的要求是纸上的墨不在笔离开后变形；预混把跳变减半、补间把它摊到 70ms，但没消除。若 T1/T2 仍能看出，可改为 liftBlend = 1（书写中尾端始终是「若此刻抬笔」的样子，代价是快写时尾巴一直是尖的）。
4. 纸纹、飞白、洇墨的 SVG 只是近似；Metal 着色器版本的观感需在 spike 上重新看，数值参数（feibaiMax、纹理强度）以真机为准。
5. Ink v3 留存数据只能近似回放（§6.4），D27 的作品化页面（字墙、字帖、年报）在 DQ2-C 之前达不到书写格的保真度。
