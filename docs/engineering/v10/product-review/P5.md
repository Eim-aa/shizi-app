# P5 需求缺口评审（视角：用户要完成的事 vs 产品里的入口）

证据范围：源码（src/ui、src/config/copy）、decisions.md D48/D55–D65、.review/benchmark/同类产品参考.md（2026-10-04 调研，含 Skritter / Ringotan / Anki / 两款「提笔忘字」竞品）、本轮补查的 Skritter / Anki 官方资料。未用模拟器，未做真实用户访谈（项目自己也承认没有，见 docs/product/01-product-context.md 第 21 行）。

## 1. 结论与打分
产品定位最贴「成年人提笔忘字」：首页题记、首练三个常忘字、大写数字、提醒文案都指向它；学生和学中文的人能用，但没有为他们做专门入口，这是有意的取舍，不建议补。核心任务（每天写一组、自判、安排复习、留下笔迹作品、备份）入口完整、步数少。缺口集中在「事后修正与管理」：误判之后的补救、把不想练的字拿出去、从结果页进到某个字。这些都是已有能力（改判、详情页、移出自选）没有被放到用户需要它的那一刻。

打分：7 / 10。主流程顺手且克制；但纠错与管理类入口断在页与页之间，用户在 20 字一组（D65）后会更频繁撞上。

## 2. 发现清单（较短）
- P5-01（中）事后无法改判。改判只在写字页结果行（src/ui/screens/write/result-row.js:228–267）和结果页对照弹层（src/ui/screens/result/index.js:529–548）。单字详情的历次笔迹放大弹层只能看（src/ui/screens/detail/records.js:379–383，只有 InkMini 与完成键）。离开结果页后，误点「写错了」的记录无法再改，它会让该字每次被排到最前（D65 #1 写错优先回来）并计入「待复习」。违反：负责人原则 1（常用纠错应一次点到）的精神；竞品 Kanji Study 点花圈可改结果、Ringotan 可推翻误判（同类产品参考.md §3 印证清单）。建议见 §3-1。
- P5-02（中）结果页的字到不了详情。结果页格子只开「对照 / 修改」弹层，仓库内 openDetail 的调用只有字库墙、清单行、查字卡、月字帖（grep 结果：library/all.js:297、list.js:289、query-entry.js:56、mine/month.js:125），没有结果页和写字页。想看写错那个字的字源、历次笔迹、下次复习日，要回字库再搜。建议见 §3-2。
- P5-03（低）详情页对非自选字没有「加入自选」。查字卡有（CharCard 的 query-card-add），详情页行列表只有「移出自选」（src/ui/screens/detail/actions.js:134–170）。同一个字，在查字里能加、在详情里不能加。

## 3. 遗漏的功能与入口（按优先级）

### 3-1 误判后改判 / 删除一条记录 —— 应该（偏必须）
- 谁、何时：所有用户。手滑点了「写错了」，或把别人（孩子）划的一笔记下来了，写完结果页之后才发现，或隔天看详情时发现。
- 现在：只能在当次结果页改判；离开后无任何入口，无删除记录能力（copy 全表检索「删除」只有备份清空，src/config/copy/backup.js）。备份「清空记录」是全清。
- 证据：代码已有能力（commit 改判、更新同一条记录，D19/D06）但详情页缺入口；竞品 Kanji Study v4.2.3 / v4.8.0「点花圈可改、可撤销」，Ringotan 评论有人用 override（同类产品参考.md §2.2、§2.3）。
- 最小做法：详情页历次笔迹放大弹层（detail-zoom）里复用结果页的「改为写对 / 改为写错」按钮（同一个弹层组件 result-row 的 change 逻辑），改判后详情「待复习」行实时变化（R-D01 已声明实时算）。不做「删除记录」：改判足以纠错，删除会让备份、字帖、年报数字变得难解释，且违反宁少勿多。点击数：详情 → 点笔迹格 → 改为…（3 步，与结果页一致）；无新增提示、无新块。
- 符合原则：是（原则 1、7；不增加提示）。

### 3-2 结果页 / 写字页判断页进入某个字的详情 —— 应该
- 谁、何时：写错一个字后想看字源、想马上多练一次、想知道几天后再见。
- 现在：结果页「回到…」→ 字库 → 搜索框输入字 → 点卡片「查看记录」。约 4–5 步。
- 最小做法：结果页对照弹层（已经由点格子打开）内，在「改为写对 / 写错」旁加一个文字按钮「看这个字 ›」，推入详情页（普通推入，符合 D62，返回回到结果页；`leaveDetail` 文案已存在，说明链路是设计过的）。不在结果页本体加行。2 步到达。
- 符合原则：弹层里多一个按钮，属于「用户能据此行动」；不增加 toast。需防止与「写字页每阶段无例外左上角返回」冲突：只放在结果页，不放写字页（写字页的回忆阶段看详情会泄露答案，是 D16 的事，所以不建议）。

### 3-3 把某个字从练习里拿出去（已熟不练 / 用不上不练） —— 应该，但优先级低于 3-1
- 谁、何时：成年人。选「常用字」库后，新字里会反复出现自己早就稳的字，或「少见字」库里永远用不到的人名地名字；每组 20 字后更明显。
- 现在：只有「跳过」，且 D65 #5 之后只管当天，次日仍会回来；「移出自选」只对自选字有效；练习范围只能整库切换。唯一的曲线救国：写对一次（首写写对记 Easy，D41），间隔会拉长，但仍会回来。
- 竞品：Skritter 的核心清理方式是 ban，且文档与论坛反复推荐「把已熟的字 ban 掉来缩队列」，并有「已 ban 词」页可恢复（Skritter 博客《List System Overhaul》2011；论坛帖「How do I remove words from my review list without banning them?」）；Anki 的 suspend / bury 与 leech 机制（Anki 手册 Leeches 页）。同类产品参考.md 也记录 Anki 的「review hell」差评，拾字用积压阀对应，但没有个人管理手段。
- 最小做法：详情页行列表加一行「不再出现」（点一次生效，下方 UndoBar，复用「移出自选」同一套 `commitRemoveCustom` 撤销机制；已有「已跳过」区域可改名承接，让被移出的字在字库「已跳过」块里可见、可恢复）。不做「已掌握」打分，不做批量。点击：字库 → 字 → 详情行，3 步；已熟字无需此功能的用户零成本。
- 符合原则：不违反 1/5；与 7 有张力（新增一类状态），建议先观察 20 字/组真机反馈再定，故标「应该」而不是「必须」。可选替代：不加功能，把「跳过」改成「今天不出现；点两次永久」——不推荐，违反规范统一。

### 3-4 听读音 —— 可以（不建议做）
- 谁：学中文的人、家长陪孩子。看到拼音 `gān` 想听一遍。
- 现在：没有任何发音能力（grep speak/tts/读音 无结果；声音只有判断 / 落款音，且 D63 已去掉开关）。
- 竞品：「提笔忘字」竞品有听写模式（同类产品参考.md §2.4）。
- 判断：目标用户是成年母语者，拼音+词语已是题面；系统 TTS 一行即可，但会引入「播放按钮」新块与静音/耳机规则。留作「可以」，不要为凑齐竞品而加。

### 3-5 个人记忆口诀 / 备注 —— 可以（D48 已定暂不做）
- 艾宾浩斯提笔忘字有「个人提示」（同类产品参考.md §2.5，灵感 #9）；D48 第 6 点负责人已决定暂不做。不重议。

### 3-6 不应补的（有意不做，附理由）
- 评分 / 打卡 / 徽章 / 补签：违反 D01、D03、原则 5。竞品「提笔忘字」做了，评论里被骂的恰是这些（同类产品参考.md §5 A1、A3）。
- 笔画实时识别、AI 纠错：违反 D03 自判。
- 账号 / 云同步 / 多孩子档案：违反纯本地定位（01-product-context）。家长陪孩子场景靠「每组字数 5」和「课本字」范围已覆盖主要需求，不建议加「多用户」。
- 字体 / 描红字帖打印：偏练字类产品，非回忆类；灵感 #7「打印题面卡」是 D46-13 纸上写的延伸，D63 已把「在纸上写」整体删掉，勿重议。

### 3-7 备份 / 换机 —— 已满足，仅提示风险（非缺口）
- 有导出、恢复、清空、撤销；关于页说明「不会自动备份，换手机前请先导出」。需求满足；备份是用户唯一的数据安全手段，且无提醒——这一条是产品决定（不催），不建议加红点，原则 5。

## 4. 入口审计表（用户需要它的那一刻）

| 用户要做的事 | 入口 | 步数 | 判断 |
|---|---|---|---|
| 今天开始写 | 首页主按钮 | 1 | 好 |
| 写字时求助 / 看答案 / 跳过 | 写字页常驻（D55） | 1 | 好 |
| 撤销 / 清空笔迹 | 页头（D53） | 1 | 好 |
| 改刚才的判断 | 写字页结果行 / 结果页弹层 | 1–2 | 好，但离开后断（P5-01） |
| 查某个字 | 字库搜索框（D60） | 2 | 好 |
| 练某个指定字 | 查字卡 / 详情「练这个字」 | 2–3 | 好 |
| 从结果页看字详情 | 无 | 4–5（绕字库） | 缺（P5-02） |
| 看历次笔迹 | 详情头图 + 记录块 | 3 | 好 |
| 改历史判断 / 删记录 | 无 | 不可能 | 缺（P5-01） |
| 把字移出练习 | 仅自选字 | — | 缺（3-3） |
| 把字加入自选 | 查字卡有，详情无 | — | 小缺（P5-03） |
| 换掉不合适的词语 | 详情「换个词语」 | 3 | 能用；但写到一半遇到怪词只能先写完再找（想换词的时刻是在写字页），可接受，不建议在写字页加入口 |
| 调每组字数 | 「我的」行内四段（D65） | 2 | 好 |
| 存图 / 分享 | 结果页分享图标、「我的」字帖、详情「做成图片」 | 1–3 | 好 |
| 备份 / 恢复 | 「我的」→ 备份 | 2 | 好 |

## 5. 做得好、应该保留
- 写字页「提示 / 看答案 / 跳过」一次点到（D55），符合负责人原则，不要收进菜单。
- 「我的」页常用设置一次点到（D63），每组字数行内四段（D65）。
- 保存成功不提示、失败三段式（原则 2）。
- 纯本地、无账号、无评分、无打卡：与竞品「提笔忘字」「练字大师」的差评点形成差异（同类产品参考.md §0、§5）。
- 笔迹留存与月字帖、年报：对应「练了不留痕」差评（A6）。
- 积压阀、写错优先回来、提示越多间隔越短（D65）：对应 Anki「review hell」。
- 字库首页「今日练习」整行直达开写（D60）。

## 6. 待证实
- 3-3 的真实频率：20 字/组下用户遇到「早已稳的字」的比例，需要看调度模拟报告新字的难度分布或真机试用；我没有跑模拟。
- 误判占比：没有数据说明用户一次会话里平均误点几次，P5-01 的优先级取决于此；可在真机测试单加一条「故意点错后试图改回」。
- 学生 / 学中文用户：项目内无这类人群的访谈；本评审对其需求只是推断，不计入发现。
- 3-4 听读音：未查证目标用户是否有此诉求。
