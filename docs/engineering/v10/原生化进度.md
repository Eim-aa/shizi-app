## 怎么跑原生检查（运行命令）

- `pnpm run verify:native-ui`：逐屏对比 + 流程用例一条命令跑完。默认 `--shards 3`：开 3 台专用模拟器并行（构建一次；取证与流程各分 3 组；计时敏感的 `NativeStageFlowTests` 最后单独在空闲机器上跑，阈值不放宽），约 1 小时；`--shards 1` 是原来的串行（2.5–3.5 小时）。
- 常用组合：`--parity-only` / `--flows-only`；`--states a,b`；`FLOW_CLASSES=A,B`（只跑几个测试类，可与 `--shards` 同用）；`--update-reference`；`KEEP_SIM=1`。各选项见 `ios/ShiziApp/scripts/verify-native-ui.sh` 头部。
- 分片的测试类耗时参考 `ios/ShiziApp/scripts/native-ui/flow-durations.json`；全量跑完后可用 `node ios/ShiziApp/scripts/native-ui/shard-plan.mjs durations <flows.md>` 刷新。
