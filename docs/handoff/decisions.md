本表整理到 2026-09-27。当前用户明确决定优先于旧附件；覆盖仅限明确讨论的部分。本文记录已有决定，不新增产品授权。通用目标见[需求全文](../product/foundation/03-需求范围与验收标准.md)。

## 已确认，可直接沿用

| ID | 决定 | 覆盖/限制与验收 |
| --- | --- | --- |
| D01 | 轻松开始、安静书写、自然停下；默认安排为主、选字为补充 | 不以每日必须完成、闯关、排名、断签惩罚推动使用；不自动评价书法美观 |
| D02 | 三导航“习字／字库／我的”；首页唯一主入口 | 无重复续练卡/常用字快捷入口；首次/无记录不显示今日零统计，标题题记弱于操作 |
| D03 | 回忆后分区对照，由用户明确自判 | 不叠字评分、不预选答案、不新增每字必经确认屏；没有本人书写不制造有效判断 |
| D04 | 术语使用提示、撤销、修改判断、备份等清楚表达 | 诗意可用于品牌文字，不能代替功能名称；完整字不能叫部分提示 |
| D05 | 普通/首次与临时自选会话隔离 | 暂停 B 时首页优先续 B；明确结束 B 后返回来源，首页可继续 A，不自动跳进 A；未结束 B 时只读查询仍可用，开始 C 不覆盖 B |
| D06 | 更正上一判断更新同一记录，入口保留到当前字提交 | 当前字落笔或跳过不清除修改入口；保留当前笔迹、阶段与帮助事实。覆盖 #173 的短时撤销/首笔关闭旧约定 |
| D07 | 保存成功才推进；失败留现场，重试不多记 | 用户明确撤销/清空本人墨迹按意图执行，不误读成“任何时候都不能变笔迹”；已发生的帮助事实不因此删除 |
| D08 | 第八稿采用简化视觉，设计师另交当前源文件 | 不恢复旧复杂桌面/红石/大量山水硬要求；冻结视觉不等于交互与生产集成已验收 |
| D09 | 点画倍数乘本体宽；短于 30ms 用整段时长；单点直径 0.9×本体宽；零时间差点合并，不参与速度计算 | 以文字规格优先，参考 JS 的点画分支是原型差异。新笔迹实现仍等真机阈值 |
| D10 | 有真实压力时，压力替代速度本体因子，不叠乘；飞白/洇墨/减少动态效果沿约定的现有处理 | 覆盖 #169 旧删除表现要求；Pencil 留真机验收，不宣称旧静态模块已实现 r8 |
| D11 | 本次图片沿现有选字成员/顺序，同字取本次最后明确判断笔迹；月图取月内最后判断 | 末次缺墨用浅参考，不用较早或别月墨迹冒充；单字图缺墨处理与月/次图分开 |
| D12 | 首页 N 沿现有定义；N≤8 显示 N 项，N>8 显示最近判断 8 项、数字仍 N | 仅已定数据契约，首页尚未接。超过 80 字导出返回 pending，不抛超量错误/不擅自截字 |
| D13 | 楷体文楷 GB 子集改名 ShiziKai；宋体 Noto Serif SC 400/500；完整许可随运行包 | 字重精确加载；宋体先固定文案+三条题记。旧语料覆盖不自动覆盖 #175 或未来句库 |
| D14 | 历史缺 t/p 如实报告，不交伪造回放工具 | 新逐判断笔迹存储另案暂停，待保留策略和真人容量；不借“没有正式用户”启动它 |
| D15 | 当前无正式用户，历史测试记录兼容不再是硬约束 | 允许必要数据调整但关联必须正确；保留已完成成果，不凭空补造来源，不无限扩展审校范围 |
| D16 | 固定 340 张内容修订落地；重复目标字全部遮住，仅原目标位置给拼音，其他用 □；必要时给可见消歧线索 | #175 已提交；954 张仅拼音题/226 组冲突继续在 #105，不能说全库语义已认证 |
