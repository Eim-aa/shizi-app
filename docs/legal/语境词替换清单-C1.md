- 落地方式：全部写进 `data/context-overrides.js`（运行时覆盖），批准记录、读音、旧词逐条在 `scripts/fixtures/content-quality-approved.json`（round 4）；`deck-data.js` 不手改，没有重跑生成器。
- 内容门禁：`scripts/verify_content_corpus.cjs` 逐条核对批准结果；替换掉的敏感词进 `scripts/fixtures/content-blocklist.json`，题面可见文字（语境词、提示、释义）不得再出现，防止重新生成题库时回潮。
- 规则：目标字在新词里只出现一次；读音逐条固定（pypinyin 读错或轻声的已人工改：师傅 fu、豆腐 fu、石榴 liu、姓翟 zhái、叱吒 zhà、姓阚 kàn）；同音会有别的自然答案时补一句字形提示；没有中性常用词的字改为释义题（只给意思或字形，不带原词）。
- 「姓X」只用于常见姓氏；同音的姓多（如 俞 / 余 / 于）时补字形提示。
- 合计 490 个字：顾问审读 1.0 审定 219 个，全库排查 271 个（其中释义题 115 个）。
- 排查后仍保留的：疾病本身的名称（癌症、肿瘤、瘟疫、痢疾、痔疮、癫痫、瘫痪——这些字本身就是病名，字义沉重的字另按 D50 ⑥ 不进默认排序）、贪污 / 贿赂、裸露、屁股、坟墓、地名与国名、jieba 误标为人名的普通词（勾勒、凤凰、黎明、山涧……）。
