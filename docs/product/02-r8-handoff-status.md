第八稿视觉已冻结；本轮先交与跨页交互无关的底层成果。页面、布局、弹层、页面动效和生产输入管线没有因底层签收而获准接入。

| 成果 | 本轮状态 | 适用边界 |
|---|---|---|
| 笔迹规格对照 | 已交付现有公式、目标差距、建议与工作量 | 新管线尚未实施；不是第八稿手感已在真机通过 |
| 字体与排版 | 三份子集字体、改名与许可材料、覆盖及拼音/竖排检查、运行/存档清单已交付 | 只按运行白名单取一个格式配置；完整上游材料不混入应用运行包 |
| 图片导出 | 独立离屏模块、人工夹具样图与限定范围检查已交付 | 收到可信数据后的选取与绘图能力；不等于页面或真实历史已接入 |
| 记录与回放字段 | 已核对记录链及 x/y/t/p 缺口 | 不补造历史时间、压力或完整回放，不交伪回放转换工具 |

首轮由用户限定签收。后续 r2 的运行/存档清单拆分、GPOS 原因说明、超 80 字正常返回待定、参考字测量使用注入画布工厂四项已交付并通过独立复核。作者测试、独立检查和用户实测是不同来源，不把计数相加当成独立用户场景数。

用户确认字体 helper 在桌面 Chrome 153 实测 7 项通过；该结果为用户提供的确认，没有改写成 AI 本轮操作日志。Safari/WKWebView、Pencil、60/120Hz 与真机手感仍未由此获得验证。补充拼音组合存在已记录的边界，不能声称任意新字符、题记或声调全部通过；新内容实际接入此字体包时须核对对应语料。

## 已确认的底层决议

- 点画倍数乘本体宽；不足 30ms 用整段时长，单点直径为本体宽的 0.9 倍，零时间差点合并后不参与速度计算。原型直接乘固定 BASE 的分支已登记为差异，不能据它推翻文字裁决。
- 有真实笔压时，以笔压替代速度因子，两者不叠乘。新笔迹管线等待原型真机确定阈值；飞白、洇墨及减少动态效果按本轮对照的现有处理界定，未宣布新管线已生产化。
- 本次图片沿现有选字成员与顺序，同字取本次最后明确判断的笔迹；月图限定在该月。末次缺墨不能借更早或别月笔迹冒充；可回退为明确标识的浅色参考。
- 首页数字 N 沿已确认口径：N≤8 显示 N 项；N>8 只显示最近判断的 8 项，数字仍为 N。本轮交的是数据方案，没有改变首页。
- 超过 80 字返回 `pending / OVER_80_POLICY_PENDING`，不截取、不分配画布；这没有决定取哪些字或落款写哪个总数。
