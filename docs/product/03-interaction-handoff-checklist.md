## 连续场景

- [ ] 首次开始→写一笔→自主判断→返回；无判断直接返回不制造有效记录，不要求完成每日任务。
- [ ] 提示→看答案→描写或自己再试→判断；本人笔迹、参考和帮助事实分开。
- [ ] 原练习有未判笔迹与帮助→临时选字→暂停→优先续临时组→明确结束→返回来源→首页可继续原练习，不自动进入下一字。
- [ ] 临时组中途结束的零判断、部分判断、保存失败分支；可以重新选组，不能覆盖尚未处理的现场。
- [ ] 查字不预选，添加输入可勾选；只有明确开始后才加入自选列表，取消无记录副作用；未结束临时组不妨碍只读查字。
- [ ] 当前字写几笔后修改上一判断；更正同一记录、不增加次数、当前现场保留，失败可重试。落笔或跳过不清除修改入口，入口留到当前字提交。
- [ ] 末次缺墨、早次有墨、全需参考、零记录分别检查；图片与备份的对象和用途清楚。
- [ ] “错→后来写对”和“错→更正为对”按明确决定检查需要再练的变化。
- [ ] 首页 N=0/1/8/9；历史月与当前月图片范围；超 80 字不擅自截字，待定策略如实显示。
- [ ] 恢复取消、坏文件、保护副本失败、覆盖失败与撤销失败各有真实后果说明；不把短暂提示时长当作副本寿命。

## 正式接入另行验证

判断、更正、返回、结束在保存成功后推进；失败保留现场。重复操作、重试或晚到响应不重复计数、不覆盖新现场。真实存储与恢复不能用“跳到成功页面”证明；必要数据调整不受旧测试记录兼容硬约束，但须保证当前关联正确。

日期记录说明事件来源，更正不伪装成新尝试；补记练习的字归实际书写日，被补日期仅记录补记标记。新存储、真机阈值、Pencil 与 Safari/WKWebView 仍按各自阶段核验。

每条验收记录版本、前置状态、实际步骤、结果、证据与未覆盖范围；模拟分支写“代表路径演示”，不写“生产保存通过”。先看新交接是否已处理，已处理的直接关闭，不要求重做视觉或重复返工。
