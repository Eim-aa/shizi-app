## 版本优先关系

1. 最新明确的产品决定优先于旧附件；决定只覆盖其明确范围。
2. 第八稿视觉冻结、9 月 25 日术语和本轮底层裁决共同组成当前依据。附件内部的“已定”不能覆盖后续明确保留的待定项。
3. 设计示例、静态截图、隔离模型和生产运行是不同层级的证据；旧报告保留当时状态，不当作当前全部通过或全部未修。
4. 旧视觉材料中的强制红石材质、桌面纸笔、大量山水植物和严格参考图还原要求已被后续简化方向替代。不得据此恢复过度装饰、打卡或强制每日任务。
