# 01 · 项目简报

版本：接手整理版 · 2026-09-27。保留前期资料的 G/E/H/R/J/O 编号；已按本 session 最新决定更新。来源与适用边界见 [总览](README.md)。

## 1. 我们在做什么

**拾字帮助已经学过汉字的人，在想写的时候轻松开始，安静地回忆和写几个字，想停就自然停下来。**

主要场景是每天或偶尔主动打开写一会儿；遇到某个字想不起写法时，查找或添加来练是补充场景。由系统提供默认练习安排，用户也能自己选字。[已确认：S01、S02]

用户不需要先选库、设目标或完成一项日任务才能开始。产品不以书法水平评定、自动判分、排行榜或连续打卡惩罚作为本轮方向。[已确认：S02、S03]

## 2. 为什么要改这一版

| 问题 | 已有依据 | 本轮应产生的变化 |
|---|---|---|
| 定位在轻松书写与任务完成之间摇摆 | 用户反对“今天已完成”等任务暗示；认可自然结束 | 开始、继续、结束的表达围绕用户意愿，记录只陈述事实 |
| 主入口被重复操作和装饰分散 | 用户指出重复续练、首页常用字入口、标题题记过强 | 首页一个明确主行动，辅助入口和品牌文字降低层级 |
| 功能名称难理解，添加能力不明显 | 用户多次指出“收字、点拨、月帖”等词语；要求明确添加 | 动作使用自然语言，用户能找到查字、添加、帮助和数据管理 |
| 方案中存在流程和数据保护风险 | 外部演示曾复现进度覆盖、跳过误计；工程查到候选缺口 | 对照、自判、纠正、暂停和临时练习形成统一规则并逐层验证 |
| 设计交接有缺页、状态缺失和口径冲突 | 设计与独立验收记录 | 用统一需求、状态和验收条件推进，避免以截图数量代替完整性 |

以上是本项目的反馈和检查结果，不是市场规模、总体用户痛点频率或商业收益的证明。[S01、S04–S09]

## 3. 本轮目标与范围

### 产品目标

- **G01 容易开始**：首次用户能理解产品用途，并找到开始写字或自己选字的入口。
- **G02 安静连续**：写字、看参考、自行判断之间停顿少；遇到不会的字可以获得帮助，也可以先写其他字。
- **G03 自然结束和恢复**：没有每日必须完成的数量；暂停后能回到原位置，临时选字不覆盖原练习。
- **G04 功能清楚且可信**：记录、统计和备份说法与实际行为一致；查字、添加、设置和既有能力完整可达。
- **G05 简洁协调**：先实现温暖纸色、墨色文字、朱红主行动和统一组件的简化版本；可读性与入口层级优先。[S01–S03]

### 本轮交付范围

三主页面及相关练习、帮助、字详情、记录、设置、图片与备份路径的设计和后续实现；保留既有真实能力。详细要求见 [需求范围](03-需求范围与验收标准.md)。

当前第八稿视觉冻结，底层已限定签收，页面交互尚待正式交接；本文件说明目标范围，不授权立即实施全部页面或数据迁移。

### 暂不纳入

新增拍照识字、登录与云端系统、诗词／名家内容平台、打卡闯关模式、书法评分；复杂红石材质、桌面纸笔和大量山水植物场景暂缓。已有照片查看能力不等于新增拍照识字；历史测试数据兼容不再是硬约束，必要调整须保持当前功能关联正确。[S02、S06]

## 4. 怎么判断这版变好了

以下为**建议采用的衡量方案，尚无基线数据，也未获得指标阈值的单独确认**。先完成首轮测试，再确定是否需要调整指标和阈值；不编造留存、活跃、时长或商业目标。

| 对应目标 | 指标与口径 | 获取方式 | 本轮判断建议 |
|---|---|---|---|
| G01 | 用途理解：参与者能否用自己的话说明“回忆汉字、自行判断、没有每日必须完成任务” | 首次无讲解探索后提问；逐项记录原话 | 核心误解即进入修改清单；不能靠主持人解释算通过 |
| G01、G04 | 无协助任务完成率：无需主持人给操作答案而完成的人次 ÷ 实际尝试人次，按任务分别计算 | 完整交互原型中的开始、添加、续写、找记录等任务 | 小样本同时报告人数和错误路径，不只报百分比 |
| G02 | 首次落笔前的耗时、误点、犹豫；完成一次写字→对照→判断的绕路次数 | 记录起止点及观察，不评价字写得好不好 | 首测建立基线；后测用相同任务和版本信息比较 |
| G03 | 能否主动停下并正确恢复；是否以为“不写完就失败” | 结束／暂停任务及开放式追问 | 不能退出、恢复错位或任务压力误解须处理 |
| G04 | 记录可信：跳过不误计、更正不增条数、失败不推进、A/B 不覆盖 | 原型、隔离工程、正式代码及真机分层验收 | 对应交付范围内出现反例即阻断该项验收；不能用满意度抵消 |
| G05 | 主入口优先被注意、文字可读、关键操作可达、三页风格一致 | 用户观察加设计走查；短屏与放大文字检查 | 主要入口被装饰抢占或操作被遮挡须修正 |

记录模板及研究方法见 [研究计划](02-研究证据与验证计划.md)。暂不引入新的线上埋点或上传个人笔迹；如后续需要，另行明确数据范围和用途。

## 6. 关键假设与风险

- **H01**：轻松回忆几个字能形成持续使用价值；现有依据主要来自产品主导者，需要目标用户验证。
- **H02**：用户愿意且能自行判断写对／写错；要观察不确定时怎么做，不以“能点击”证明理解。
- **H03**：默认安排足以降低开始成本，自己选字作为补充入口能被发现。
- **H04**：简化视觉能更好地突出主入口，同时保留产品气质。
- **H05**：两屏流程、帮助与自然停止能降低负担；需要连续任务而非逐张截图测试。
- **H06**：已定 A/B 恢复优先级、帮助历史和统计表达能被理解，不造成“刚才的内容丢了”的感觉。

优先研究 H01、H02、H03、H05；H06 同时依赖交互验证和工程证据。完整验证安排见研究文件。
