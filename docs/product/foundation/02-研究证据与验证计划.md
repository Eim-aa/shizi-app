# 02 · 研究证据与验证计划

版本：接手整理版 · 2026-09-27。保留前期资料的 G/E/H/R/J/O 编号；已按本 session 最新决定更新。来源与适用边界见 [总览](README.md)。

## 1. 目前知道什么，不知道什么

我们掌握了产品主导者的多轮体验反馈、外部分析师交付的评审和演示、内部设计检查及有限工程验证。它们能帮助发现问题、明确产品方向，**不能证明目标用户群的需求强度、行为频率或普遍偏好**。

当前没有可用于本轮结论的目标用户招募记录、完整访谈记录、可用性测试样本或留存数据。用户称分析师在不了解项目和代码的情况下查看原型；尚未提供其目标用户资格、招募方式及统一测试条件，不把该材料算作正式用户样本。[S01、S04]

## 2. 候选用户分组

下表是按任务划分的**招募假设**，不是已经验证的人物画像；不虚构年龄、职业或市场占比。同一人可能属于多组。

| 分组 | 已具备条件／动机假设 | 需要完成的任务 | 需确认的问题 |
|---|---|---|---|
| A：想写一会儿的人（主场景） | 已学过中文，愿意偶尔在手机上回忆和书写汉字 | 不费心设置就开始，写几个字，随时停下 | 是否真的有这种需求；多久发生；手机手写是否舒适 |
| B：想起某个具体字的人（补充场景） | 对一个字的写法不确定，或想特意练它 | 输入／查找、选择、写一遍，回到之前的事情 | 添加入口是否易找；查答案是否已足够；是否还愿意练习 |
| C：回访与积累的人（跨场景） | 已经有练习和未完成内容 | 继续上次、看记录、再练、保管数据 | 对记录和“需要再练”的理解；恢复和备份预期 |

本轮不以儿童识字、专业书法训练或考试词库学习作为主要招募目的。不能据此推断这些人绝不会使用产品。[产品范围：S02]

## 3. 现有证据与发现

| 证据 | 观察／原话 | 适用范围与解释 | 对应行动 |
|---|---|---|---|
| E01 · 用户意图 | “每天或者偶尔想练的时候自己打开，安静地写几个字” | 产品主导者确认的主场景；不是发生频率调查 | 以轻松开始、默认安排为主；R01、R02 |
| E02 · 用户体验 | 用户指出“接着上次写”与主入口“继续写字”重复；“今天已完成”暗示有任务 | 对当时首页稿的具体反馈；是否困扰其他人待测 | 单一主入口，不用日任务完成语言；R01、R08 |
| E03 · 用户理解 | 用户要求提示、撤销等直接表达，反对“点拨”“收字”“月帖”等操作命名；要求明确添加 | 当时文案确实让该用户产生困惑；不能宣称所有诗意文案有害 | 品牌文案与操作文案区别处理；R09、R11、R13 |
| E04 · 用户理解 | 用户指出首次未使用，不能根据前几次练习了解难度；反对“了解你的书写情况”的书法感 | 首次流程中的逻辑和定位问题 | 不虚构个性化依据；解释为回忆字形，自行判断；R02 |
| E05 · 用户视觉反馈 | 用户认为标题题记过强，后来明确先做简洁版本 | 当前决策；不是已证明简洁版本转化更高 | 中央入口优先，简化材质；R13，验证 H04 |
| E06 · 外部评审建议 | 分析师指出每字三屏及困难路径的停顿风险，建议集中输入选择、显示当前字库等 | S04 汇总的外部判断；无目标用户样本统计 | 已授权吸收部分为两屏流程、输入复用；R03、R09、R10 |
| E07 · 旧演示实测 | 在外部演示中，临时单字练习返回后原进度消失；直接跳过被记为写对及练过 | S04 当时版本的复现，不代表现行生产发生同样结果 | 会话隔离、跳过不误计成为验收重点；R05、R07、R08 |
| E08 · 静态与演示核查 | 完整淡字被当成部分提示；更正可能再次累加计数 | S04 分别注明演示／源码证据；并非用户行为研究 | 明确部分提示与答案，更正同一条记录；R04、R06 |
| E09 · 内部结构评审 | Q3-D 检查 51 个样例、62 次观察，发现保存失败路径、资源失败和上限文案问题；D2.1 定向修订 | S07；样例和观察次数不是参与者人数 | 保留失败状态及示例边界，继续交互验证；R07、R09、R14 |
| E10 · 工程证据 | 隔离存储模型修复两项问题，独立复核在列明场景内关闭 | S08；不是正式产品、真实数据或所有崩溃场景验证 | 作为实现依据，后续仍须生产接入和真机验收；R06–R08、R14 |

**目前能得出的研究结论**：这些证据足以支持纠正重复入口、含糊操作语言和明确的记录错误；尚不足以证明整体产品价值、使用频率或最终流程对目标用户都成立。

## 4. 待验证假设与反证

| 假设 | 怎样验证 | 哪些观察会使我们重新考虑 |
|---|---|---|
| H01：轻松回忆汉字有真实使用价值 | 先问近期真实经历和现有做法，再体验原型 | 只能认同概念但没有对应经历；手机写字的成本始终超过收益 |
| H02：用户能独立自判且理解不自动评分 | 无讲解完成写字和对照，观察选择并追问 | 等待系统评分、误以为笔迹美观决定对错、无法判断却被迫选择 |
| H03：默认开始与自己选字满足主要需求 | 分别给自由写一会儿、想练指定字两类任务 | 频繁找不到选字；先选库的需求明显高于预期；开始前必须解释 |
| H04：简化视觉突出行动且仍有气质 | 在高保真代表页观察第一注意点、辨识与主观评价 | 主按钮不明显、装饰被误认为操作、文字看不清；美感喜好与任务表现分别记录 |
| H05：两屏自判与可放下减轻负担 | 连续写多个字，安排不确定或不会的情况 | 用户仍觉得每字步骤太多；以为必须看完、描完或写对才可离开 |
| H06：暂停／结束与 A/B 优先级可以理解 | 保存常规练习，临时选字后分别暂停和结束再返回 | 用户把暂停当完成；找不到普通进度；担心新练习覆盖旧内容 |

## 5. 第一轮研究计划（建议，尚未执行）

### 招募与方式

建议先找 **5 位符合候选条件的参与者**进行小规模探索，不作为统计代表样本；至少涵盖想自由写、曾忘记具体字、愿意回访三类经历，可重叠。产品主导者的体验单独记录，不计入这 5 位；设计师、工程或 AI 自检不代替目标参与者。

产品负责人负责安排与记录，设计角色观察交互问题，独立验收角色检查结论是否有证据。每人建议约 30–40 分钟，允许调整。只在参与者知情同意后记录屏幕或声音；无录制也可做匿名笔记。使用测试数据，不操作其真实备份。

访谈可先做；交互任务须等连续原型具备相应行为。静态图可用于理解和命名测试，不能用于证明会话保存可用。

### 先问经历，再看方案

1. 最近一次你想写一个汉字却想不起写法，是什么时候？当时在做什么？后来怎么处理？
2. 最近一次你主动拿起笔或在屏幕上写汉字，是为什么？写了多久，为什么停？
3. 你现在有保存想练的字或查看练习记录的做法吗？能举最近一次吗？
4. 你会怎样判断自己刚才写的字是否正确？不确定时会怎么办？

避免先问“你是不是喜欢轻松、不打卡的 App”，也不把“每天写字一定有帮助”当作问题前提。没有相关经历本身就是结果。

### 不泄露按钮答案的任务

| 测试任务 | 给参与者的场景 | 观察点／完成条件 |
|---|---|---|
| T01 首次开始 | “你现在有一点空闲，想用它写一会儿。请按自己的想法试试。” | 能解释用途、开始并落笔；是否误认为书法评分或必须完成全部首次内容 |
| T02 不确定写法 | “碰到一个你不太确定怎么写的字，请按平时的习惯处理。” | 能找到合适帮助、区分自己写的与参考；不强制其选择某种帮助 |
| T03 自己选择 | “你这次特别想练‘茶’和‘雨’，请试着安排。” | 能发现入口、理解选择范围；不因纯输入建立练习记录 |
| T04 临时离开 | “你现在有事要离开，稍后还想从这里接着写。” | 能保存并恢复原阶段；记录所求帮助及主持人干预 |
| T05 另一段练习 | 预置未完成普通练习：“你想先练一个自己想到的字，写完再回到刚才的内容。” | 临时任务和原进度均可找到；分别测试暂停、明确结束的理解 |
| T06 判断改错 | “你刚才的对错判断点反了，请处理；当前这页已经写了几笔。” | 更正可发现，知道改的是哪一次；原笔迹不受影响 |
| T07 看记录与保管 | “你想看看自己最近写了什么，并把资料留一份以备换手机。” | 找得到记录和备份；不会误认为已自动云同步 |

首次自由探索在前；其余任务可轮换顺序，记录练习效应。不会某字不能靠强迫参与者装不会来证明真实需求；预置困难状态用于检验路径时应注明“模拟场景”。

### 记录和分析

每条记录至少填写：参与者匿名编号、招募条件、原型版本、设备／字号、任务与前置数据、操作原话、是否独立完成、时间起止、停顿／误点／求助、结果证据、观察与解释、问题严重程度。

记录示例仅作格式：`观察：参与者在首页寻找原进度 20 秒并求助。解释假设：继续入口语义不清。` 未实际测试前不填入真实结果表，也不虚构引语。

问题排序：数据丢失或错误记录先修；不能完成关键任务或产生核心误解其次；再处理绕路、层级和审美。针对关键改动复测，并保留“仍不确定”而非强行归因。

## 6. 研究完成后必须交付

- 匿名样本说明、实际执行的任务和版本，以及未做的部分。
- 每条发现对应原话／行为证据、受影响任务、替代解释和人数。
- 哪些假设获支持、被反驳或仍不确定；不能把一次任务成功当作长期需求证明。
- 更新后的需求、改动优先级和复测结论。

**当前空缺**：目标用户研究尚未执行；以上不填写虚构的成功率或满意度。研究结果可能改变我们的方案，不能只用来给既定设计背书。
