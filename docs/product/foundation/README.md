## 如何理解证据

- **已确认**是产品主导者明确决定，不表示代码已完成。
- **已观察**只支持注明版本与场景，不外推到所有用户、所有设备或生产环境。
- **建议/假设**是待验证方案，例如 5 人、每人 30–40 分钟的研究安排，不是已经招募的样本或新增预算承诺。
- **待定/暂缓**不由演示默认值解决，按责任和阶段条件处理。
