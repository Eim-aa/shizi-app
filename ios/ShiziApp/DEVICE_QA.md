# 拾字第十稿 · 真机检查清单（M7）

适用版本：`v10/integration`（第十稿重建，数据 v2、备份 version 2、Service Worker `shizi-v14-<BUILD>`）。旧版（v9 及以前）的拍字 / OCR、字卡、补帖、盖章、校准、背景音、里程碑等检查项已随功能删除，不再列出。

本清单由**产品负责人或测试**在真机上执行，工程不代填。它收齐了 02-实现计划 §9 点名的项，以及 `docs/engineering/v10/acceptance/` 下 M0–M6 各份验收记录「未覆盖范围」里写明留给 M7 / 真机的全部条目；每行的「来源」列写出处，便于回填验收记录。

填写方式：

- 每行三栏结果「通过 / 未通过 / 未覆盖」只勾一个；「未覆盖」= 这次没测到（缺机型、缺条件），不等于通过。
- 「备注」写设备编号（见 §1.2，例如 D1）和证据文件名。证据统一放 `docs/engineering/v10/acceptance/M7/`（截图、录屏、Web Inspector 输出、smoke JSON、备份文件）。
- 「未通过」请另记：复现步骤、期望、实际、设备与 iOS 版本、证据文件。单台设备通过不代表全部机型通过。
- 涉及主观判断的项（手感、观感、档位选择）写结论和理由，例如「.05 档，.06 在 D2 上偏黄」。

## 13f. 阶段 2 入场券 · 原生书写面 spike 真机测量（P1-S2；T1，T2 预备）

**iPhone 13（60Hz）上怎么做**（产品负责人；约 30 分钟）：

1. 安装带开关的 Debug 包（Mac 上，iPhone 用线连好、已信任）：

   （`CONFIGURATION` 默认就是 Debug。用 Xcode 也行：Scheme `Shizi` → Edit Scheme → Run → Arguments → Arguments Passed On Launch 加 `-shizi-native-ink` 与 `-shizi-ink-selfcheck`，Build Configuration 选 Debug。）
2. 以后每次从主屏图标打开不会带开关——**要测时都用第 1 步的命令重新启动一次**（或在 Xcode 里 Run）。
3. 进写字页（首页「开始写字」或任一字详情「练这个字」）。写字方式要是「在屏幕上写」。
4. 按下面的表写字。每写完一笔，App 会把延迟统计存一次。
5. **导出**：在书写格上**两指同时轻点两下**，弹出分享面板，选「存储到文件」或 AirDrop 到 Mac，文件名 `拾字-原生书写面-T1-<时间>.json`。没导出成功也不要紧：Mac 上 `xcrun devicectl device copy from --device '<设备>' --domain-type appDataContainer --domain-identifier <bundle id> --source Documents/shizi-native-ink-latency.json --destination ./` 可直接取回。
6. 把 JSON、录像和备注交给工程（放 `.review/s2-spike/device/`）。

## 13g. 阶段 1 · 左缘右滑返回（卡 R4-G1；03 P270 / P271 / P272）的真机验收

- B25-04 判断落定：点「写对了 / 写错了」，笔迹离纸收进页头计数，轻触感与离纸同一刻；故意断开存储（模拟失败）时不落定、不震，出现「没保存上，你写的字还在。/ 先不保存 / 再试一次」。
- B25-05 结果行「修改 ›」：下一个字未落笔时可见，点开弹层（你写的 / 标准写法 / 说明 / 改为……）；改后行变「已改为……」，只改这一次；落笔后「修改 ›」收起；看过答案的字没有「修改 ›」。
