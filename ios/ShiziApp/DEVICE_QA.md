## 自动真机 Smoke

- [ ] `signing-preflight.sh` 通过，设备状态为 available。
- [ ] 运行 `DEVICE_ID='设备名称或 UUID' SIGNING_XCCONFIG=ios/ShiziApp/Config/Signing.local.xcconfig ios/ShiziApp/scripts/smoke-device.sh`。
- [ ] 普通模式两次 native smoke 均通过，第二次确认 `localStorage` 跨进程重启保留。
- [ ] Smoke 的 `handwritingFlow` 全部通过，确认 pointer 轨迹能落墨且触摸滚动被阻止。
- [ ] Smoke 的软件键盘严格检查通过，`keyboardInsetActive` 为 true，输入框和确认按钮均可达。
- [ ] 加 `DEV_MODE=1` 再跑一次，确认题库质检入口可见且流程通过。
- [ ] 将 `ios/ShiziApp/build/device-smoke/` 下的 JSON 结果随验收记录保留。

- [ ] 字库无月份碎片，浓 / 正 / 淡三档墨色在真机上可辨。输入已收字立即高亮并在约 800ms 后开详情；在库未收字出现「收进字库」；未知字显示「字库里暂时找不到『X』」。请保留一张真机截图。
- [ ] 单字详情无手写时显示虚线空纸格，不用范字冒充；有手写时可在并排与「叠」之间切换；今年日期不带年份。
- [ ] 在 375×667 与 375×812、浅色与深色下分别打开「水」的详情：故事区只增加一行较小较淡的「众水并流，象流水形——《说文解字》」，不横向溢出、不增加新层级；再打开「的」，确认整行安静缺席。
- [ ] 「最近写不稳的字」中每个事实数字只来自真实没写出次数；分类不足 3 个字时不显示，深色模式行文清晰。
- [ ] 习字页常驻只见「点拨 / 不会写 / 写好了」；落笔后才浮出右上「撤一笔 / 重写」，且无提示配额数字、圆脸贴纸或收字入口。
- [ ] 首次点「点拨」出现一次说明；轻点播放下一组，按住瞥一眼完整字形，松开立即恢复且不增加提示次数。
- [ ] 从字库详情进入单字练习时不显示 0/1；返回后回到字库，首页不会出现续练 0/1。
- [ ] 将 `shizi.opens.v1` 改成对象或把任一启动键写成非法 JSON 后重启：App 正常进入首页，顶部提示已隔离，原值出现在 `shizi.corrupt.<key>`。

- [ ] 设置、最近写不稳、年度报告、题库质检二级页均使用左上 44pt 圆形 `‹` 返回。
- [ ] 在题库质检中能看到疑似「X字」与常见音译词报告；打开对应详情只显示单字和拼音，不展示可疑词。

## 手写练习

- [ ] 用手指分别慢写、快写、写长横与捺：慢笔明显更饱满，快笔更轻且只有若有若无的飞白；起笔不鼓包，收笔自然出锋，停顿墨晕不超过约 2pt。录一段新旧手感对比。
- [ ] 写「十 / 木」等交叉字，让后一笔快速穿过先前墨迹与已显示点拨：飞白只出现在当前笔画内，不得在交叉处挖掉旧笔、提示层或米字格；详情最近手写、日帖和月帖也保持相同叠笔关系。
- [ ] Apple Pencil 轻压 / 重压的笔宽有连续差异，快速移动仍保持 60fps；用 Instruments 或真机帧率录制留下 SE2 级性能证据。
- [ ] 开启「减少动态效果」后仍有首尾锥形，但飞白与洇墨关闭；写同一个字前后，自动比对结论不因笔锋效果改变。
- [ ] 完成一组后检查详情最近手写、日帖和月帖：都保留练习时的粗细变化，不退回等宽线；恢复旧备份的历史墨迹也不异常变细。

## 沉浸练习

- [ ] 首次落笔时顶栏、题面和底部动作保持可见，首笔抬起后约 200ms 内完全退场；后续每笔在按下时立即退场，字格角落工具始终约三成可见且可点。
- [ ] 停笔或手指离开字格 2 秒后控件恢复；自由书写和「第 1 步：描红」都一致，不会因进入揭晓、重写、退出或切后台而卡在隐藏态。请录一段完整状态变化。
- [ ] 开启 VoiceOver 或外接键盘：灶台退场后不能聚焦或触发返回、题面和底部动作，焦点不会留在隐藏控件；字格角落的可用工具仍可访问，2 秒恢复后动作重新可达。
- [ ] 每次从首页或字库进入练习，只有首卡出现一次不超过 400ms 的轻纸面揭开；同组换题和恢复未完成组不重复。
- [ ] 结果页大章下只有一句克制收笔语，不新增计时或进度；校准与普通组都可读。
- [ ] 「我的 → 设置 → 练字背景音」默认关；雨声与炉火分别试听至少 2 分钟，循环无明显接缝、音量显著低于盖章声，静音键拨下时保持安静。
- [ ] 关闭纸墨声音后，已选的雨声 / 炉火仍正常；进入结果、返回首页、锁屏或切后台时背景音淡出，回到练习才恢复。
- [ ] 在背景音淡出的半秒内快速返回练习，并连续切换雨声 / 炉火 10 次；始终只听到当前场景，不叠音、不持续升高 CPU 或耗电。
- [ ] 开启系统「减少动态效果」后，灶台控件直接显隐，首卡不播放揭纸动画，其余书写与声景逻辑不变。
- [ ] 进入写字页后田字格尺寸正常，没有被安全区或底部区域遮挡。
- [ ] 320×568 小屏上开启「更大字体」后，276px 字格、引导文字、字格角落的「点拨 / 撤一笔 / 重写」和「不会写 / 写好了」全部在首屏内，页面不可滚动。
- [ ] 手指在田字格内书写流畅，笔迹不断裂、延迟可接受。
- [ ] 手指写字时页面不滚动、不回弹。
- [ ] 「撤一笔」按动作倒序回退：写一笔、看一组点拨、再写一笔后，连续点三次依次撤回笔画、点拨组、笔画；点拨组回退瞬时重绘且不闪烁。
- [ ] 普通习字点「重写」会把墨迹和已显示点拨全部清空；已经用过点拨的账不回退，主按钮仍为「写好了」，重看同一组点拨不重复记账。
- [ ] 落笔中及抬笔后约 300ms，「不会写 / 写好了」不会被手掌误触；点拨动画结束前也不能提交。
- [ ] 轻点字格左上「点拨」可以播放下一组笔画，播放后仍能继续书写；按钮不显示配额数字。
- [ ] 双指或意外三指进入透视后，任一指抬起/取消都立即恢复；余下手指移动不续写，全部离开后下一次落笔正常。
- [ ] 按住字格左上「点拨」时真实完整字形出现、墨迹淡出，松手立即恢复，且不改变提示次数或本回合结果归类。
- [ ] 双指按住仍可透视；任一指松开时完整字形与提示立即隐藏，行为与可见按钮一致。
- [ ] 看一组或多组提示、只补写剩余笔画后提交：揭晓页左侧标注「你写的」，画面包含仍可见的提示和用户墨迹，自动比对按完整字格给建议。
- [ ] 看多组提示后撤销最后一组：提交快照只含仍可见的提示；全部撤销后完整写对仍自动归类为「稍后再练」，不能当场毕业。
- [ ] 在提示笔画上重复描画不会被机械判为多余笔画；无笔顺数据时自动助手降级但用户仍能判断。
- [ ] 结果页有「写对了 / 写错了」两个明确动作和小号「不太确定」；不太确定盖「补拾」、本组稍后再写且不直接毕业。
- [ ] 未用提示且逐笔几何检查明确判差时，点「写对了」只弹一次内联确认；「再对一眼」不记账且同次揭晓不重复弹，「确定写对了」仍按用户选择毕业。
- [ ] 笔画数不同的整体覆盖度检查、自动检查不可用和用过提示的回合均不弹软确认；反馈期点「重盖」后重新选择写对会再次确认。
- [ ] 不看提示写对自动盖「拾到」，用过提示写对自动盖「补拾」，自由书写选错自动盖「待补」，点「不会写」自动盖「再拾」。
- [ ] 看过提示后选择写错只增加一条 slow / Again；每个真实回忆回合最多一条 FSRS 事件，不出现 Hard / Easy。
- [ ] 自动盖章后点击盖章、Toast 或结果区会立即换题；连续快速点两次不会跨过下一题，无操作时约 1.8 秒自动换题。
- [ ] 困难字反馈只说明稍后再写一次，不提前显示跨天日期；反馈期「重盖」仍优先回滚而不是换题。
- [ ] 反馈期点「重盖」回到同一份提交快照；记忆、再练队列、今日不同字/尝试次数和 FSRS 事件全部原子回滚。

## 不会写教学

- [ ] 全新安装进入校准首卡，字与画布渲染完成后「点拨 / 不会写」立即可点；落笔不会重新开始等待，页面明确提示“写不出就点不会写”。
- [ ] 校准首张应为「尴」、第二张应为「嚏」；最后四张不出现明显高于中段的极难字，首次选择写错、不太确定、用提示或不会写时只出现一次“一时想不起来很正常”宽慰。
- [ ] 点「不会写」后立即进入「第 1 步：描红」，不先出现结果、盖章、等待动画或确认弹层；同一个字再次求助也完整进入两步教学。
- [ ] 全 App 首次说明直接显示在描红页内，画布同时可写；第一笔有效描迹后自然收起并记为已看，未落笔返回或强杀后仍会显示。
- [ ] 第 1 步轮廓可见，只保留「撤一笔 / 重描 / 描好了，下一步自己写」；主按钮初始不可用，实际落笔后才可用。
- [ ] 进入第 2 步后轮廓、fallback 字形、描红墨迹和点拨全部消失，只保留「撤一笔 / 重写 / 再描一遍 / 写好了」。
- [ ] 第 2 步选择写错会回到第 1 步；选择写对后不写 Good，仍需本组稍后不看提示写对。
- [ ] 第 1 步、第 2 步和教学完成反馈期间退出再进入，都恢复同一目标字、墨迹与教学阶段。

## 本组再练与返回

- [ ] 看提示写出、写错、不会写都会在本组稍后重现，默认尽量隔两个其他回合，不等待 6/12 小时。
- [ ] 分别让困难字出现在第 1、14、15 位：第 1 位尽量隔两题；第 14/15 位不足间隔时可回转，不提前结算也不卡死。
- [ ] 同一个字连续失败至少 10 次、或组里只剩一个困难字时仍可继续；今日不同字只加 1，尝试次数逐次增加。
- [ ] 普通组达到 20 次尝试或约 6 分钟时，只在换题间隙出现一次节奏提醒；选择「继续练」后本组不再重复出现，首次校准不会被截断。
- [ ] 节奏提醒选择「明天接着拾」后，未解决字按原队列顺序出现在下一组最前面；已覆盖完整基础组时今日完成态成立，未覆盖的短组不误记完成。
- [ ] 再次提示、写错或不会写继续留在队列；只有全新回合不看提示、不描红并确认写对才毕业。
- [ ] 新组首张显示「已练 0 / 15 个」；第一次提交后显示「已练 1 / 15 个」；同字再练、描红和教学第 2 步不重复增加已练数。
- [ ] 目标未全部覆盖时显示「已练 X / Y 个 · 另有 N 个字要再练」；全部覆盖但仍未毕业时只显示「另有 N 个字要再练」，同字多个待办只计 1。
- [ ] 320 / 375 / 390 / 430pt、动态字体、Y > 15、N 为两位数时顶栏不换行，不与返回重叠；不存在点阵或图形进度条。
- [ ] 375×667 下从校准首卡直接点「不会写」，完整走过「第 1 步：描红 → 第 2 步：自己写」；两个阶段底部按钮完整可见可点，进度与屏幕中线对齐。
- [ ] 375pt 宽揭晓页点「看笔顺」，范字的右侧与末笔完整显示在 138pt 字格内，不出现右/下裁切。
- [ ] 跨卡重盖浮条存续的 5 秒内，返回/进度/收字顶栏被完整替代；浮条消失或开始落笔后顶栏恢复，页面不跳位。
- [ ] 首次校准揭晓显示「对错你说了算，没有考试」且不重复吉祥物建议；无助手建议时写对/写错同权，明确建议任一侧时仅该侧成为主按钮。
- [ ] 浅色与深色分别检查首页、单字详情、字库和“我的”：浅色为暖生宣白而非冷灰白，深色为暖黑纸；正文、淡墨字墙和边界均清晰可读。
- [ ] 章印落下有一次短促墨晕；反馈吉祥物在拾到/已独立时欣慰、写错/不会写时关切、补拾时平静，不挤动反馈文案。开启系统「减少动态效果」后墨晕和眨眼停止。
- [ ] 结算页每个基础字只出现一次，保留首次困难标签，并为已毕业困难字显示「已独立」。
- [ ] 「不想练」会从当前再练队列中排除并记为隐藏，不伪装成独立写出，也不永久卡住本组。
- [ ] new / review / focus / calibrate 四种入口都遵守同一完成条件。
- [ ] 顶部显示标准返回符号，点击区至少 44 × 44pt；点击返回与左缘侧滑都直接保存并回首页，不出现退出确认、“进度已保存”Toast，或旧主页 / 练习页闪帧。
- [ ] 收字面板打开时，第一次返回只关闭面板；再次返回才离开习字。首页左缘侧滑无习字退出行为。
- [ ] 连续执行至少 3 次“进入未完成组 → 左缘侧滑 → 首页 → 续练”；每次恢复同一字、阶段、墨迹、提示、撤销状态和队列，不前跳、不重复记账、不堆 history。
- [ ] 模拟存储空间不足或写入失败时，返回留在当前练习并提示重试；恢复写入后才能回首页。

## 本地数据

- [ ] 完成至少一题后退出并重启 App，已拾字/再拾/复习状态仍存在。
- [ ] 未完成组退出后首页显示续练态；重启后恢复 recall、tracing、postTraceRecall、revealDecision、reinforcement 五种状态中的原状态。
- [ ] 在每种状态分别杀掉 App 再启动，墨迹、可见提示、提交快照、教学阶段和队列不丢、不重复记账。
- [ ] 将未完成组跨过本地午夜再打开，仍优先继续原组；不同字数不重复增加，昨天的组不被错误结算。
- [ ] 完成第一组后首页固定显示「今日已拾 N 个字」；到期不足 15 字的短组做完也算完成，加练或新增到期字不会把完成态改回未完成。
- [ ] 快速连点盖章、重写等控件不会触发页面双击缩放，双指捏合缩放仍可用。
- [ ] 完成后加练一组，今日计数继续累加；中途退出显示「继续加练这组」。
- [ ] 首页「拾字第 N 天」按累计练习日显示：当天完整做完第一组才 +1，只盖几章或只打开不计，同日加练不重复计。
- [ ] 首页不显示本月天数、连续天数、到期数或其他数字卡；本月练习天数只在“我的”嵌入印历中显示，且不设目标或欠账。
