# 拾字 · 真机检查清单

适用：纯原生 App（UIKit + ShiziCore，App 里没有 JS / WKWebView，D84）。

本清单由**产品负责人或测试**在真机上执行，工程不代填。**先跑自动检查**（§1.1 的 P1、P2），自动检查覆盖不到的才留在这里：手感（跟手、Pencil、120Hz）、真实系统面板、读屏实际播报、听感、户外观感、真机性能与耐久性。

旧版本里与网页 / PWA / WKWebView / Web Inspector 相关的检查项（CSSOM 注入、Service Worker 升级与离线、localStorage 配额、控制台语句等）已随网页版删除；需要时看 Git 历史（D84 清扫前的提交）。

填写方式：

- 每行三栏结果「通过 / 未通过 / 未覆盖」只勾一个；「未覆盖」= 这次没测到（缺机型、缺条件），不等于通过。
- 「备注」写设备编号（见 §1.2，例如 D1）和证据文件名。证据统一放 `docs/engineering/v10/acceptance/M7/`（截图、录屏、量测 JSON、备份文件）。
- 「未通过」请另记：复现步骤、期望、实际、设备与 iOS 版本、证据文件。单台设备通过不代表全部机型通过。
- 涉及主观判断的项（手感、观感、档位选择）写结论和理由。

## 13j. 判断页与改判（卡 B2.5；确认单 5；D19 / D46 ⑪ / D49 / D55）

- B25-01 判断页：上下两格同一顶边、同一中线、中间只有一条细线；页头「‹」/ 标题 / 右侧计数；题面空格里没有答案。
- B25-02 两键：进页约 0.3s 后淡出现（半透明，点不动），约 0.44s 变实可点；两键长得一样，没有哪个被选中或着色；系统「减少动态效果」开启或开着 VoiceOver 时进页就能点。
- B25-03 「‹ 接着写」与左缘右滑：上格长回书写格、参考格和两键淡出，笔迹原样；手指拖一半松开会回弹，过了阈值才回到书写格；倒放过程中落笔，动画立刻到位、这一笔照常写。
- B25-04 判断落定：点「写对了 / 写错了」，笔迹离纸收进页头计数，轻触感与离纸同一刻；保存失败时不落定、不震，出现「没保存上，你写的字还在。/ 先不保存 / 再试一次」。
- B25-05 结果行「修改 ›」：下一个字未落笔时可见，点开弹层（你写的 / 标准写法 / 说明 / 改为……）；改后行变「已改为……」，只改这一次；落笔后「修改 ›」收起；看过答案的字没有「修改 ›」。
