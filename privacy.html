拾字

隐私政策

最后更新：2026-08-30

拾字把你的练习数据全部留在你自己的设备上。没有账号，没有服务器，没有分析 SDK，没有广告。 本页的每一条断言都能在公开仓库里核对，并且由 scripts/verify_privacy_claims.py 持续校验：代码一旦不再符合这里的说法，构建就会失败。

一、拾字存了什么，存在哪里

全部存在你这台设备上——网页版存在浏览器的 localStorage 与 Service Worker 缓存里，iOS 版存在 App 沙箱里。

内容存储位置说明
练习进度与每个字的记忆状态shizi.deck.* / shizi.memory.v1见过几次、写对写错、下次该复习的日子
复习日志shizi.fsrsReviewLog.v1逐条只留 120 天，更早的压成月度计数
日历与练习日shizi.activity.v1哪天练了、盖了几章
偏好设置shizi.pref.v1 等字号、声景、在学字库、提醒开关
本地漏斗计数shizi.funnel.v1见下方第四节
你自己加的字、拍到的字shizi.added.v1 / shizi.wild.v1拍字照片也在这里，见第三节
题库、笔顺、界面资源Service Worker 缓存为了断网也能练

卸载 App、或在浏览器里清除本站数据，以上内容全部消失，且无法从任何地方恢复——因为别处没有副本。

二、拾字不做什么

这些都可以在公开仓库里核对：

  • 没有账号，不需要注册，也不收集姓名、手机号、邮箱。
  • 不向任何第三方发送数据。App 发出的全部网络请求都指向同源的 data/*.json（笔顺与字源数据）；index.html 与 Service Worker 全文没有出现任何外部域名。
  • 没有分析、埋点上报或广告 SDK，没有 XMLHttpRequest、sendBeacon、WebSocket。
  • 不使用 Cookie，不使用 IndexedDB，不读取定位。
  • iOS 原生层不发起任何网络请求——工程里没有 URLSession。唯一涉及外部地址的代码，是你主动点击链接时把它交给系统浏览器打开。
  • App 的隐私清单 PrivacyInfo.xcprivacy 声明：不做追踪，收集的数据类型为空，追踪域名为空。

三、摄像头与照片

拍字入盒

你可以拍下生活中遇到的字。识别在你的设备上完成，用的是 Apple 系统自带的 Vision 框架，照片不上传。识别只给出候选字，最终选哪个字始终由你确认。

请注意这一点：拍到的照片保存在本机的 shizi.wild.v1 里，而它属于备份范围。 当你主动导出备份文件时，照片会包含在这个文件中。备份文件由你自己保管；你把它发给谁，谁就能看到里面的照片。

这与 App 内相机权限说明的口径一致，不是额外的例外。

保存字卡到相册

把手写字卡存进系统相册时需要相册写入权限。拾字只写入，不读取你的相册。

四、本地漏斗是什么

App 内记了几个计数，用来判断产品本身有没有做对：首次启动、校准首卡完成、校准完成、次日回访、导出过备份，以及每组练习的时长。

  • 它不含任何设备标识、账号标识、IP 或位置。
  • 它只写在你的设备上，不会自动发送到任何地方。
  • 只有在你主动导出备份、并且主动把这个文件交给开发者时，开发者才会看到它。你随时可以不这么做。

五、托管方能看到什么

这一条不是拾字的收集行为，但确实存在，所以写在这里：

  • 网页版托管在 GitHub Pages。你打开页面时，GitHub 作为 Web 服务器会按通常方式记录请求（IP 地址、时间、User-Agent、请求了哪个文件）。这部分适用 GitHub 的隐私政策，拾字既不控制也读不到。
  • iOS App 从 App 内部读取资源，正常使用时不经过这条路径。

六、你的控制权

  • 导出备份：把全部数据导出成一个 JSON 文件，存到你想存的地方。
  • 导入备份：换设备时用它恢复。
  • 清空全部数据：App 内一键清除。
  • 卸载即删除：没有服务端副本需要另行申请删除。

七、儿童

拾字不收集任何个人信息，因此不针对年龄做区分收集。App 内没有社交功能、没有用户生成内容的公开展示、没有站外链接推荐。

八、变更

本页如有变更，会更新顶部的日期，并在仓库的提交历史里留下完整记录。

九、联系

有任何隐私相关的问题，请在 GitHub Issues 提出，或见支持页。
