拾字

支持

打字多了，有些字提笔就忘。拾字帮你把这些字重新写熟。

怎么开始

  • 打开 拾字，先做一次校准，让它知道哪些字对你是难的。
  • 之后每天来写一组。写不出来的字会更频繁地回来，写熟了的字会拉长间隔。
  • 在手机浏览器里选「添加到主屏幕」，它就能像 App 一样离线打开。

常见问题

我的数据存在哪里？会丢吗？

全部存在你这台设备上，没有服务器副本。所以两件事同时成立：别人拿不到它，你自己也要负责保管它。 清除浏览器数据、卸载 App 都会让它消失。建议定期用「导出备份」存一份。详见隐私政策。

换手机了怎么办？

旧设备上导出备份，把文件传到新设备，再用「导入备份」恢复。导入会覆盖新设备上已有的数据，导入前请先确认。

没网能用吗？

能。首次打开后，题库、笔顺和界面都会缓存到本地。断网时照常练习，联网后自动更新到最新版本。

有的字没有笔顺动画？

笔顺数据来自开源的 Hanzi Writer 数据集，它没有覆盖全部汉字。遇到这种字，卡片上会说明，你仍然可以自己判断写对没有，点「写好了」或「不会写」。

拍字识别不准怎么办？

识别只负责给候选，最终选哪个字由你点。如果候选里没有你要的字，可以直接手动输入。

提醒不响？

提醒默认是关闭的，需要你在设置里主动打开，并允许系统通知权限。它只在 iOS App 里可用。

能删除我的数据吗？

可以，而且不需要联系任何人：App 内「清空全部数据」，或直接卸载。没有服务端副本需要另行申请删除。

报告问题

请到 GitHub Issues 提交。为了能复现，请尽量附上：

  • 设备与系统版本（例如 iPhone 13 / iOS 17.4），以及用的是网页版还是 App
  • 你做了什么、期望看到什么、实际看到什么
  • 截图或录屏

附备份文件前请先想一下。备份里包含你的练习记录，如果你用过拍字功能，还包含你拍下的照片。 GitHub Issue 是公开的。除非确认里面没有你不想公开的内容，否则不要把备份贴上去。
